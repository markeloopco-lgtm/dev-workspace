# トーク動画の自動カット編集ツール

しゃべり動画を文字起こしして、間・言いよどみ・言い直しをカットし、テロップを入れて書き出す。
編集内容は **Markdownの編集プラン（`edit_plan.md`）** で管理する。スマホでも読めて、直せば動画に反映される。

## 流れ

```
元動画（12GBなど大きくてもOK）
  │ prepare.py      … 作業用の軽い動画(540p)と音声を作る（HDRは通常の色に変換）
  │ transcribe.py   … 文字起こし（Whisper・無料・単語ごとの時刻つき）
  │ build_edit.py --init … 編集プランの下書き（言いよどみは自動でカット済み）
  ▼
video_edit/projects/<名前>/edit_plan.md   ← ここを直す（Claudeが言い直しや誤字を整理 → 人が確認）
  │ build_edit.py   … プランからカット位置(edit.json)とテロップ(telops.ass)を作る
  │ render.py --preview … 確認用の軽い動画 → スマホで確認
  ▼
OKなら PC で render.py --source 元動画 … 完成版（1920x1080・元の画質から）
```

## 編集プランの書き方

```markdown
## 本編

### ■ 向いてる人①            ← 見出し（画面左上に出る。次の文から）
- 012 (01:23) ~~えー、~~今日は**ジャーナリング**について話します
- 013 (01:27) ~~それではは じめ~~                ← 行ごと取り消し線 = まるごとカット
- 014 (01:30) それでは始めます
> ポイントは**3つ**！          ← 直前の文の頭で、画面中央に大きく出る
```

| 書き方 | 意味 |
|---|---|
| 行頭の `012 (01:23)` | 文の番号と元動画の時刻。**消さない**（音声の位置の目印） |
| `~~ ~~` | その部分をカット（音声も映像も消える）。行ごと消してもカット |
| 文字を書き換える | テロップの文字だけが変わる（誤字直しなど）。音声は消えない |
| `**太字**` | 強調色のテロップ |
| `／` | テロップをそこで区切る |
| `### 見出し` / `### -` | 見出しを出す / 消す |
| `> 文字` | 画面中央の大きいテロップ |
| `［メモ：…］` | テロップに出ないメモ |

`## 設定` の欄で、間の詰め具合・ズーム・色・文字数・音量などを変えられる。

## 完成版をPCで書き出す（Windows）

```powershell
winget install Gyan.FFmpeg            # 初回だけ（入れたらPowerShellを開き直す）
cd <このリポジトリ>
git pull
python -m venv .venv                  # 初回だけ
.venv\Scripts\pip install numpy       # 初回だけ
.venv\Scripts\python video_edit\render.py --name <名前> --source "D:\動画\元動画.MP4"
```

- NVIDIAのGPU（RTX 3050など）があれば自動で使う。無ければCPUで書き出す
- 出力は元動画と同じフォルダに `<元の名前>_編集済み.mp4`
- 元動画の長さが編集データと違うときは、別のファイルと判断して止まる

## ファイル

| パス | 内容 |
|---|---|
| `prepare.py` / `transcribe.py` / `build_edit.py` / `render.py` | 上の流れの各工程 |
| `projects/<名前>/` | 編集プラン・文字起こし・カット位置・テロップ（コミットする） |
| `fonts/` | テロップ用フォント M PLUS Rounded 1c（SIL OFL。`OFL.txt` 参照） |
| `selftest.py` | 合成動画での通し検証（カット・映像と音声の同期・テロップ・HDR変換） |
| `../work/<名前>/` | 作業用の動画・音声（大容量のためコミットしない） |
