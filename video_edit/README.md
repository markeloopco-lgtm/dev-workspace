# トーク動画の自動カット編集ツール

しゃべり動画を文字起こしして、間・言いよどみ・言い直しをカットし、テロップを入れて書き出す。
編集内容は **Markdownの編集プラン（`edit_plan.md`）** で管理する。スマホでも読めて、直せば動画に反映される。
横長の動画は 1920x1080、縦型（スマホ縦撮り・ショート）は 1080x1920 で書き出す（元動画の向きで自動判定）。

## 全部自動でやる（Windows）

リポジトリ直下の **`自動編集.bat` に動画ファイルをドラッグ＆ドロップ**する。それだけ。

- 初回だけ: Python が無ければ入れる → 作業用環境(.venv)と文字起こし用ライブラリを入れる → ffmpeg が無ければ入れる
  （Python や ffmpeg を新しく入れたときは「もう一度ドラッグして」と出るので、その通りにする）
- 途中で画面上部に出すタイトルを聞かれる（「／」で2行。空のままEnterで無し）
- 以降は 素材の軽量化 → 文字起こし → 言いよどみ・言い直しの自動カット → テロップ → キラキラ等の演出 → 書き出し まで自動
- 出来上がりは元動画と同じフォルダの `<元の名前>_編集済み.mp4`
- 途中で止まっても、同じ動画をもう一度ドラッグすれば続きから再開する
- 仕上がりを直したいときは `video_edit/projects/<名前>/edit_plan.md` を書き換えて、もう一度ドラッグ（手直しは上書きされない）

コマンドで実行する場合（Mac/Linux も同じ）:

```powershell
python video_edit\auto_edit.py "D:\動画\元動画.mp4" --title "タイトル1行目／2行目"
```

| オプション | 意味 |
|---|---|
| `--title` | 画面上部にずっと出すタイトル（縦型ではお手本と同じ上部中央の帯） |
| `--prompt` | 文字起こしのヒント（人名・専門用語。認識精度が上がる。Whisperのみ） |
| `--engine ja` | 日本語専用の文字起こし（ReazonSpeech）を使う。速い（74秒の音声が約3秒）。要モデル、下記 |
| `--no-fx` | キラキラ等の演出を乗せない |
| `--from-analysis analysis/<名前>` | お手本を `video_style` で解析した結果から、演出の頻度を真似る |
| `--preview` | 確認用の軽い動画だけ作る |
| `--redo` / `--redo-plan` | 全工程 / 編集プランだけ やり直す |

自動でやらないこと: 文字起こしの誤字直し、強調語（**太字**）や大テロップ（`> `）の指定。
これらは `edit_plan.md` を直すと反映される（Claude に任せることもできる）。

## 流れ

```
元動画（12GBなど大きくてもOK）
  │ prepare.py      … 作業用の軽い動画(540p)と音声を作る（HDRは通常の色に変換）
  │ transcribe.py   … 文字起こし（Whisper・無料・単語ごとの時刻つき）
  │ build_edit.py --init … 編集プランの下書き（言いよどみは自動でカット済み）
  ▼
video_edit/projects/<名前>/edit_plan.md   ← ここを直す（Claudeが言い直しや誤字を整理 → 人が確認）
  │ build_edit.py   … プランからカット位置(edit.json)とテロップ(telops.ass)を作る
  │ render.py --preview … 確認用の軽い動画 → スマホで確認
  ▼
OKなら PC で render.py --source 元動画 … 完成版（元の画質から。横長1920x1080／縦型1080x1920）
```

キラキラ等の演出を乗せる場合は、`render.py` の前に2つ挟む。

```
make_assets.py    … キラキラ・白発光の透過素材を生成（外部素材・有料素材は不要）
make_fx_plan.py   … カット頭のどこに置くかを決めて effects.json を書く
```

`effects.json` があると `render.py` が自動で読んで重ねる。乗せたくないときは `--no-fx`。

## 編集プランの書き方

```markdown
## 本編

### ■ 向いてる人①            ← 見出し（画面左上に出る。次の文から）
- 012 (01:23) ~~えー、~~今日は**ジャーナリング**について話します
- 013 (01:27) ~~それではは じめ~~                ← 行ごと取り消し線 = まるごとカット
- 014 (01:30) それでは始めます
> ポイントは**3つ**！          ← 直前の文の頭で、画面中央に大きく出る
```

| 書き方 | 意味 |
|---|---|
| 行頭の `012 (01:23)` | 文の番号と元動画の時刻。**消さない**（音声の位置の目印） |
| `~~ ~~` | その部分をカット（音声も映像も消える）。行ごと消してもカット |
| 文字を書き換える | テロップの文字だけが変わる（誤字直しなど）。音声は消えない |
| `**太字**` | 強調色のテロップ |
| `／` | テロップをそこで区切る |
| `### 見出し` / `### -` | 見出しを出す / 消す |
| `> 文字` | 画面中央の大きいテロップ |
| `［メモ：…］` | テロップに出ないメモ |

`## 設定` の欄で、間の詰め具合・ズーム・色・文字数・音量などを変えられる。

## 完成版をPCで書き出す（Windows）

```powershell
winget install Gyan.FFmpeg            # 初回だけ（入れたらPowerShellを開き直す）
cd <このリポジトリ>
git pull
python -m venv .venv                  # 初回だけ
.venv\Scripts\pip install numpy       # 初回だけ
.venv\Scripts\python video_edit\render.py --name <名前> --source "D:\動画\元動画.MP4"
```

- NVIDIAのGPU（RTX 3050など）があれば自動で使う。無ければCPUで書き出す
- 出力は元動画と同じフォルダに `<元の名前>_編集済み.mp4`
- 元動画の長さが編集データと違うときは、別のファイルと判断して止まる

## ファイル

| パス | 内容 |
|---|---|
| `auto_edit.py` | 全工程を自動で通す（終わった工程は飛ばすので再開できる）。`自動編集.bat` から呼ばれる |
| `../自動編集.bat` | Windows用の起動ファイル。動画をドラッグ＆ドロップ（ダブルクリックならファイル選択） |
| `prepare.py` / `transcribe.py` / `build_edit.py` / `render.py` | 上の流れの各工程 |
| `transcribe_ja.py` | 日本語専用の文字起こし（sherpa-onnx + ReazonSpeech）。`transcribe.py` と同じ形式で出力する。Whisper のモデル置き場(Hugging Face)に届かない環境用。`pip install sherpa-onnx` と、GitHub の k2-fsa/sherpa-onnx の asr-models リリースから `sherpa-onnx-zipformer-ja-reazonspeech-2024-08-01` と `silero_vad.onnx` を `work/asr_models/` に置く |
| `make_assets.py` | キラキラ（ピンク系パーティクル）と白発光の透過素材を計算で生成 |
| `make_fx_plan.py` | 演出の配置を決めて `effects.json` を書く。`--from-analysis` で `video_style/` の解析結果から出現密度を引き継げる |
| `projects/<名前>/` | 編集プラン・文字起こし・カット位置・テロップ・演出の配置（コミットする） |
| `projects/<名前>/assets/` | 演出の透過素材（`make_assets.py` が生成。差し替え可） |
| `fonts/` | テロップ用フォント M PLUS Rounded 1c（SIL OFL。`OFL.txt` 参照） |
| `selftest.py` | 合成動画での通し検証（カット・映像と音声の同期・テロップ・HDR変換・縦型の全自動） |
| `../work/<名前>/` | 作業用の動画・音声（大容量のためコミットしない） |
