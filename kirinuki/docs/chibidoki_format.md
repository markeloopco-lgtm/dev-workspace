# チビドキ日本語切り抜きチャンネル 構成研究(2026-08調査)

## 研究対象

- [チビドキ日本語切り抜き【Chibidoki】](https://www.youtube.com/@%E3%83%81%E3%83%93%E3%83%89%E3%82%AD%E5%88%87%E3%82%8A%E6%8A%9C%E3%81%8D)(非公式ファンチャンネル)ほか、ワールドミント【チビドキ日本語】等の複数チャンネル
- Chibidoki本人: 米国の個人系VTuber(Mythic Talent所属)。YouTube登録約130万人。
  VTuber Awards「Most Interesting VTuber」を2023・2024の2年連続受賞。発狂・絶叫・カオス+かわいい系

## 観測した勝ちパターン(構成要素)

1. **Shorts(縦型)主体**: 人気動画のほぼ全てが /shorts/。1本=1ネタ、20〜60秒
2. **タイトル=フックの一文**(【】プレフィックスを付けず、状況をそのまま書く):
   - 「日本語で配信内容を話すチビドキなんですが…」(余韻止め型)
   - 「視聴者にチビドキ描いてもらった結果…」(結果引き型)
   - 「日本語であいさつするチビが可愛すぎる」(感想型)
   - 「チビドキが変な日本語を覚える」(三人称ナレ型)
   - 末尾にハッシュタグ: `#chibidoki #vtuber切り抜き #shorts`
3. **ネタ選定は「日本語・日本絡み」最優先**: 日本語を話す/変な日本語を覚える/日本のファンとやり取り。
   次点で音ネタ(絶叫・アニメ声ゲップ等)、かわいいリアクション
4. **前置きゼロのコールドオープン**+テンポ重視(チャンネル説明文でも「見やすくテンポの良い翻訳切り抜き」を明言)
5. **上部に状況説明テロップ、下部に大きな日本語字幕**(+小さな英語原文)
6. 長尺(横型)は補助枠: ゲーム実況のpartもの。タイトル末尾に検索ワード羅列【chibidoki/海外vtuber/切り抜き/英語学習】
