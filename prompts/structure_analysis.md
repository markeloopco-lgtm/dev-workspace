# 構成分析プロンプト（Claude Codeに渡す）

参考動画の「構成の型」を抽象化して、台本作りに使える形にする。

```
prompts/structure_analysis.md を読んで、analysis/<動画ID> の構成を分析してください。
```

複数本を分析した後は:

```
prompts/structure_analysis.md の「まとめ」の手順で configs/structure_template.md を作ってください。
```

---

## あなた（Claude）への指示

### 1本ずつの分析

`analysis/<動画ID>/` の次のファイルを読む:

- `transcript.json`（台詞と時刻）または `audio.json` の `segments`
- `shots.json`（ショットの時刻・カメラワーク・テロップ率）
- `profile.json`（数値の要約）
- あれば `gemini_watch.md` / `vlm.json`（映像の意味の分析）
- 必要なら `contact_sheet.jpg` を画像として見る（ユーザーには、画像・文字起こしがAnthropicに送信されることを伝える）

`analysis/<動画ID>/structure.md` に次をまとめる:

1. **区間表**: 開始〜終了時刻、区間の役割（つかみ／導入／本題1…／山場／まとめ／告知）、
   その区間の長さと全体に占める割合、平均ショット長
2. **つかみ（冒頭30秒）の作り**: 何秒で問いが出るか、どんな驚きで引っ張るか
3. **驚きのリズム**: 新しい事実・展開が何秒ごとに来るか（時刻の一覧）
4. **掛け合い**: 話者の交代頻度、各話者の役割（進行・解説・ツッコミ等）
5. **映像と台詞の対応**: どんな台詞の時にどんな画・カメラワークになるか（傾向を3〜5個）

### 守ること

- 台詞の**引用は10文字以内**に留め、基本は「〜について説明」のように要約で書く
  （目的は型の抽出であって台本の複製ではない）
- キャラクター名・固有の設定はそのまま型に入れない（「専門家役」「体験役」のように役割で書く）

### まとめ（複数本分析した後）

各 `analysis/*/structure.md` から共通する型を抜き出して `configs/structure_template.md` に書く:

- 標準の区間構成と、各区間の尺の目安（全体比 %）
- つかみのパターン（2〜3種）
- 驚きを入れる間隔の目安
- 話者の役割分担の型

`configs/structure_template.md` は抽象化した型だけなのでコミットしてよい。
