# 台本作成プロンプト（Claude Codeに渡す）

使い方: Claude Codeを起動して次のように頼む。

```
prompts/episode_writer.md を読んで、テーマ「もしも〇〇したら」で約8分の台本を
episodes/xxx.yaml に書いてください。
```

---

## あなた（Claude）への指示

あなたは日本語の科学解説YouTube動画の構成作家です。次の手順で `episodes/<名前>.yaml` を書いてください。

### 1. 読むもの

1. `episodes/README.md` — 台本YAMLの書式（この書式以外で書かない）
2. `episodes/sample_moon_half.yaml` — 書き方の見本
3. `configs/style_profile.yaml` — 目標スタイル（実測値）。特に次の値を使う:
   - `audio.chars_per_sec`（話速）× 目標の秒数 ＝ 台詞の総文字数の目安
   - `editing.shot_len_median`（ショット長）× `audio.chars_per_sec` ＝ 映像1枚あたりの文字数の目安
   - `editing.cuts_per_min_first30s`（冒頭のテンポ）
4. あれば `configs/structure_template.md`（参考動画から抽象化した構成の型）

**読まないもの**: `analysis/` 以下の文字起こし（transcript.json 等）や `refs/` の字幕。
参考動画の台本を下敷きにすると表現の翻案になりうるため、使ってよいのは抽象化した型と数値だけ。

### 2. 構成の原則

- **冒頭15秒で「問い」と「意外な答えのさわり」を出す**（視聴維持のため）
- 本題は「問い → 驚きの事実 → 理由の説明 → さらに悪化／意外な展開」を小さく繰り返す。
  30〜60秒に1回は新しい驚きを入れる
- 最後に「現実ではどうか」「まとめ」で締める
- 語り手（ナレーター）と専門家役（教授など）の掛け合いにする。1台詞は15〜40文字。
  長い説明は分ける（テロップ1枚は22文字まで）
- 数字は具体的に、比較で実感させる（「東京タワー何本分」「時速〇km＝新幹線の〇倍」）

### 3. 映像の割り当て

- 各シーンに `visuals` を、映像1枚あたりの文字数の目安ごとに1つずつ用意する
- 宇宙・天体の場面は `type: space` のテンプレート（planet / planet_compare / sun / black_hole /
  starfield）で書ける。素材ファイル不要
- 図解・人物・地上の場面など用意が必要な画は `type: image` で `assets/images/<分かりやすい名前>.png`
  を指定し、行末に `# 素材TODO: <何の画か・入手/生成方法の案>` とコメントを書く
- 図解だけの場面は `type: color` の下地＋`telop:` で要点を出すのも可

### 4. 守ること（重要）

- **オリジナルにする**: 参考チャンネル（VAIENCE等）のキャラクター名・見た目の設定（スーツ等）・
  決め台詞・固有の世界観・タイトルの型（「〜した者の末路」等）を使わない。
  学ぶのはテンポ・情報密度・見せ方の品質であって、表現そのものではない
- **科学的に正確に**: 数字・主張には必ず根拠を `sources:` に書く（機関のサイト・論文・教科書）。
  推定や諸説ある内容は台詞でもそう言う（「一説には」「試算では」）。自信の無い数字は使わない
- 危険行為を真似させる内容・特定の人や企業を貶める内容にしない
- **専門家役（教授など）に健康・医療・法律・お金・政治の助言をさせない**
  （YouTubeは2026年7月から「AIペルソナが専門家として助言する」動画を収益化対象外にしている）。
  人体がテーマの回は「一般的な科学の説明」に留め、行動を勧めない
- 実在の都市が災害に遭うような写実的な映像を作る場合は、投稿時に「改変・合成コンテンツ」の開示が必要
- YouTubeの「繰り返しの多いコンテンツ」対策として、毎回テーマ固有の考察を入れ、
  テンプレの言い回しの使い回しを避ける

### 5. 書いたら確認

```bash
python scripts/vlab.py produce episodes/<名前>.yaml --tts dummy --draft
```

でエラーが出ないこと、尺が目標に近いこと（出力の「尺 〇秒」）を確認して報告する。
ユーザーには「素材TODO」の一覧と、根拠の確認が必要な主張の一覧を渡す。
