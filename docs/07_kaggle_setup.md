# 07. Kaggle 無料GPUの準備

このリポジトリのノートブックは2本とも Kaggle の無料GPU枠で動く。
初回だけ必要なアカウント準備をまとめる。**所要15分ほど。費用はかからない。**

| ノートブック | 用途 | 参照ドキュメント |
|---|---|---|
| `notebooks/see_through_free_gpu.ipynb` | 一枚絵のレイヤー分解 | docs/02 |
| `notebooks/transcribe_free_gpu.ipynb` | 日本語の文字起こし | docs/06 |

## なぜ Kaggle か

Colabと違い、**週30時間という枠が数字で見える**。残り何時間使えるかが画面で確認でき、
毎週決まったタイミングでリセットされるため計画が立てやすい。
Colabは上限が非公開で、超えると突然24時間ほど使えなくなる（docs/06 参照）。

両方使えるようにしておき、**普段はKaggle、混雑時はColab**という二本立てにするのが安全。

## 手順1: アカウント登録

1. [kaggle.com](https://www.kaggle.com/) を開く → 右上 **Register**
2. Googleアカウントで登録するのが一番早い（`markeloop.co@gmail.com` でよい）
3. ユーザー名を決める（後から変更しにくいので慎重に。公開される）
4. 登録したメールアドレスに確認メールが届くので、リンクを踏んで認証する

## 手順2: 電話番号認証（これが必須）

**認証しないとGPUもインターネットも使えない。** ノートブックが動かないので必ずやる。

1. 右上のアイコン → **Settings**
2. **Phone Verification** の欄で国（Japan +81）を選び、携帯番号を入力
3. SMSで届いた6桁のコードを入力

> 番号の先頭の0は外す形式になることがある（090... → 90...）。画面の例示に従う。

これで以下が解禁される:

- GPU / TPU アクセラレータ
- ノートブックからのインターネット接続（`pip install` やモデルのダウンロードに必須）

## 手順3: ノートブックを取り込む

1. 左メニュー **Create** → **New Notebook**
2. 開いたら **File → Import Notebook**
3. このリポジトリから落とした `.ipynb` をドラッグ＆ドロップ

> リポジトリからのファイルの取得方法は docs/05 を参照。
> GitHubの該当ファイルページで「Download raw file」でも取得できる。

## 手順4: セッション設定（毎回確認する）

ノートブック画面の**右パネル**（見えなければ右上の `<` で開く）:

| 項目 | 設定 |
|---|---|
| **Accelerator** | **GPU T4 x2**（無ければ P100） |
| **Internet** | **On** |
| Persistence | 変更不要 |

Acceleratorを変えるとセッションが再起動する。**設定してからセルを実行する**こと。

> Internet が Off のままだと、モデルのダウンロードで失敗する。
> 「接続できない」系のエラーが出たらまずここを疑う。

## 手順5: 自分のファイルを渡す

Kaggleは Colab と違い、ノートブックに直接ドラッグ＆ドロップでは渡せない。
**入力ファイルはデータセットとして追加する**という作法になっている。

1. 右パネルの **「+ Add Input」**
2. 上部タブの **「Upload」** を選ぶ
3. 音声や一枚絵をドラッグ＆ドロップ → データセット名を付けて **Create**
4. 追加されると `/kaggle/input/<データセット名>/` に読み取り専用でマウントされる

ノートブック側は `/kaggle/input/` 以下を自動で探すように書いてあるので、
**パスを書き換える必要はない**。3)のセルを実行してファイル名が表示されればOK。

## 手順6: 結果を持ち帰る

出力は `/kaggle/working/` に置かれる。右パネルの **Output**（またはファイル一覧）から
zipをダウンロードする。

**セッションを閉じると `/kaggle/working` の中身は消える。** 必ずダウンロードしてから閉じる。

## 無料枠の制限

| 項目 | 制限 |
|---|---|
| GPU使用量 | **週30時間**（残量は右パネル / Settings で確認できる） |
| 1セッションの最長実行 | 約9時間（GPU使用時） |
| アイドル切断 | **20分**操作しないと停止する |
| `/kaggle/working` の保存容量 | 約20GB |

文字起こしもレイヤー分解も1回あたり数分〜十数分なので、週30時間はかなり余裕がある。
枠を無駄にしないコツ:

- 終わったら右上 **Stop Session**（またはブラウザを閉じる前に停止）
- 複数ファイルは**まとめて1セッションで処理する**（モデルの再ダウンロードを避けられる）
- 席を外す時は止める。20分は意外と早く来る

## つまずきやすい点

| 症状 | 原因と対処 |
|---|---|
| Acceleratorに GPU が出てこない | 電話番号認証が未完了。手順2をやる |
| `pip install` やモデルDLが失敗する | Internet が Off。右パネルで On にする |
| 「+ Add Input」した音声が見つからない | データセットの作成が完了していない。左メニュー Datasets で存在を確認 |
| 実行中に突然止まった | 20分のアイドル切断か9時間の上限。長い音声は分割する |
| GPU枠を使い切った | 週の残量が0。Colabに切り替える（docs/06） |
