# 06. 参考動画の編集をフレーム単位で解析する（同じ編集を再現するための「編集レシピ」）

YouTubeのURLを1つ渡すと、**ダウンロード → 全フレーム解析 → 編集レシピ（数値）とレポート**を作る。
GPU不要・無料。10分の動画で数分。

```powershell
.venv\Scripts\python scripts\analyze_video.py "https://youtu.be/TbPqMCwK7IA"
```

## 何がわかるか

| 項目 | 出てくる数値 |
|---|---|
| カットのテンポ | 1分あたりの編集点数、編集点の間隔（中央値・短い方/長い方）、冒頭30秒の密度、1分ごとの推移 |
| カットの種類 | 普通のカット / ズームカット（倍率・拡大の中心）/ ジャンプカット（同じ構図で人物だけ飛ぶ） |
| トランジション | ディゾルブ / 黒・白フェード（アウト/インのフレーム数）/ 白フラッシュ / その他のアニメ |
| カメラワーク | ショット内のズーム（倍率・秒数・加減速）/ パン・スクロール / シェイク |
| テロップ | スタイル別に: 位置・文字の高さ・塗りと縁の色・縁の太さ・座布団の有無・出方（ポップ/フェード/スライド等とフレーム数）・表示時間 |
| 常駐要素 | ロゴ・常設の見出し帯など、ずっと同じ場所にある物 |
| 音声 | ラウドネス（LUFS）、声の「間」の長さ（ジェットカットの詰め具合）、BGMの有無と声との音量差、効果音がテロップやカットに合わせて鳴っている割合 |

寸法は動画の解像度によらず **1080p換算の画素数** で出る（編集ソフトの1920×1080プロジェクトにそのまま使える）。

## 権利の注意（必読）

- 参考動画の映像・音声・切り出した画像の著作権は制作者にある。このツールは**編集の技法を数値にするため**のもの
- 解析結果（特に `frames/` `sheets/` の画像）は手元での研究用にとどめ、**公開・再配布しない**
- 再現するのは**編集の仕方だけ**。映像・音声・テロップの文言を自分の動画に流用しない
- YouTubeの利用規約は原則としてダウンロードを認めていない。私的な研究の範囲で、自己責任で行う
- `output/` はGitに入らない設定（.gitignore）なので、動画や解析結果がリポジトリに上がることはない

## A. 自分のWindows PCで実行する（おすすめ）

YouTubeはクラウド（データセンター）からのダウンロードを「bot」として拒否することが多い。家のPCなら通りやすい。

### Step 1: Pythonの確認

PowerShellで:

```powershell
python --version
```

`Python 3.10` 以上ならOK。無ければ https://www.python.org/downloads/ からインストール
（インストーラ最初の画面で **「Add python.exe to PATH」にチェック**）。

### Step 2: 解析ツールの準備（初回のみ）

docs/05でクローンしたフォルダで、このツールが入ったブランチに切り替えてから準備する
（まだクローンしていなければ docs/05 のStep 3で `-b claude/video-frame-analysis-edit-wa8q7l` を指定）:

```powershell
cd $HOME\Documents\dev-workspace
git fetch origin
git checkout claude/video-frame-analysis-edit-wa8q7l
```

ffmpeg（動画処理）とyt-dlp（ダウンロード）もこれで入る。別途インストールは不要。

`[OK] 合成動画(900フレーム)の…` と出ればよい（正解つきのテスト動画を作って解析し、答え合わせをする）。

## B. クラウド（Claude Code on the web）で実行する

初期設定（ネットワークアクセス「Trusted」）では **YouTubeへの接続がブロックされている**。許可する手順:

1. セッション画面上部の環境名（クラウドのアイコン）から環境の設定を開き、編集する
2. **Network access** を **Custom** にする
3. **Allowed domains** に次を1行ずつ入れる
   ```
   youtube.com
   *.youtube.com
   *.googlevideo.com
   *.ytimg.com
   youtu.be
   ```
4. **Also include default list of common package managers** にチェック（pip等を使うため）→ 保存

（手早くやるなら Network access を **Full** にしても動く。終わったら元に戻すとよい）

注意:
- 設定は新しく始めたセッションから効く場合がある
- 許可しても、YouTube側がクラウドのIPを「bot」と判定して拒否することがある。その場合はAで実行する

## 困ったとき

| 症状 | 対処 |
|---|---|
| `Sign in to confirm you're not a bot` | Firefoxで一度YouTubeにログインしてから `--cookies-from-browser firefox` を付けて再実行（Chromeは暗号化の都合で失敗しやすい） |
| JavaScript / `n challenge` 関連のエラー | `.venv\Scripts\pip install -U "yt-dlp[default]" deno` で更新してから再実行 |
| 動画ファイルは手元にある | URLの代わりにパスを渡す: `...\analyze_video.py C:\path\video.mp4` |
| ダウンロードだけしたい | `--download-only` を付ける |

## 精度（正解つき合成動画での検証）

`tests/run_video_selftest.py` は、解説動画でよく使う編集（カット・ズームカット・ケンバーンズ・ディゾルブ・
黒フェード・白フラッシュ・ジャンプカット・シェイク・テロップ5種・常駐ロゴ・声＋BGM＋効果音）を
フレーム番号の正解つきで仕込んだ動画を作り、答え合わせをする。現在の結果:

| 項目 | 正解 → 検出 |
|---|---|
| カット・トランジションの位置 | 全7か所をフレーム単位で一致（誤検出なし） |
| ズームカット | 1.30倍・中心(0.60, 0.40) → 1.30倍・中心(0.60, 0.40) |
| ケンバーンズ | 1.20倍 → 1.19〜1.20倍 |
| テロップの出現・差し替え・消え | 全タイミングをフレーム単位で一致 |
| テロップの出方 | フェードイン6f・ポップ(はね返りあり)6f を判別 |
| テロップの色・縁の太さ | 白/黒・黄/赤を判別、縁の太さは誤差1割前後 |
| BGM | -38 dBFS → -38.0 dBFS |
| 効果音 | 6個中6個を検出、テロップ出現との同期率80%（偶然なら5%） |

日本語テロップ＋画面収録（チャット出力が流れる・スクロール・テロップの下でズーム・アバターの瞬き）の
合成動画でも、テロップの色と出方、スクロールとズームの区別、UIの文字とテロップの区別を確認済み。

## 仕組み（ざっくり）

1. **全フレーム走査**（長辺640px）: 画面を16×9のマスに分け、マスごとの変化量とカメラの動き（特徴点追跡）を毎フレーム記録
2. **検出**: 画面の大部分が一気に変わる＝カット、じわっと入れ替わる＝トランジション、
   一部だけ変わる＝テロップ等。カメラの動き（ズーム・スクロール）は打ち消してから比べる
3. **精査**: 必要なフレームだけ取り出して、テロップの位置・出方・種類を判定。色と縁の太さは元の解像度で測り直す
4. **音声**: ラウドネス、声の途切れ、音の立ち上がり（効果音候補）とカット・テロップの同時性

## 限界

- カットと**同時に**切り替わるテロップは数えられない（テロップ回数は少なめに出る）
- フォント名は自動判定できない（`sheets/telop_styles.jpg` で目視）
- 効果音の**種類**（ポン・シャキーン等）は判定しない（鳴っているか・どこに合わせているかだけ）
- 塗りと背景が同じ色（白い画面に白文字）で文字が細いと、色の推定がぶれることがある
- 画面内の小さな文字（チャット出力など）は「UIの文字」として別に数え、テロップには入れない

## 次のステップ: 同じ編集を再現する

`recipe.json` の数値を使って、次のどちらか（または両方）を作る:

1. **編集ソフトのテンプレート**: DaVinci Resolve無料版・CapCut・ゆっくりMovieMaker4 等で、
   テロップのスタイル・カット間隔・ズーム・BGM音量を同じにする設定表
2. **自動編集スクリプト**: 自分の素材（AITuberの配信録画、画面収録＋Style-Bert-VITS2の音声など）に、
   無音カット・テロップ・ズーム・効果音・BGMを同じ数値で自動でかける（ffmpegベース・無料）

どちらにするかは、解析結果（report.md と sheets/ の画像）を見てから決める。
