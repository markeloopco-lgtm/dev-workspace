# 06. 参考チャンネルのフレーム分析（同じクオリティの動画を作るための下調べ）

参考にしたいYouTube動画を**フレーム単位で測って**、「何秒ごとに画面が変わるか」
「字幕は何秒ごとに差し替わるか」「図解は何フレームかけて出てくるか」「音量はどれくらいか」
といった制作上の数値と、目で確かめるための画像を自動で書き出す手順。
道具は `scripts/analyze_video.py`（GPU不要、ffmpegは同梱）。

```
チャンネルURL ──channel──▶ 動画一覧・長さ・再生数・タイトル傾向・サムネ一覧
                             │ 分析する動画を選ぶ
                             ▼
動画URL/録画ファイル ──video──▶ 全フレームの差分を計測
                                  ├─ 数値: テンポ・領域ごとの更新間隔・音量・間・話速
                                  └─ 画像: レイアウト・ヒートマップ・タイムライン・連番フレーム
                                        ▼
                            Claudeが画像を見て「制作仕様書」に書き起こす（Step 3）
```

## わかること

| 知りたいこと | 見る出力 |
|---|---|
| 画面の基本レイアウト（キャラ・字幕枠・図解の位置） | `images/median_layout.png`（動画全体の中央値合成） |
| 画面のどこがよく動くか | `images/change_heatmap.png` と report の3章 |
| 場面転換のテンポ（1場面の長さ） | report の2章「場面転換の間隔」 |
| 字幕が何秒ごとに差し替わるか | report の3章で「字幕(テロップ)帯?」の行 |
| 口パク・まばたきの頻度 | 同「口パク?」「まばたき?」の行 |
| 図解の出方（何フレームかけて出るか） | report の2章「アニメーションの長さ」＋ `strip_*_anim_*.jpg` |
| カット・トランジションの中身 | `strip_*_cut_*.jpg` / `strip_*_transition_*.jpg`（1フレームずつ並ぶ） |
| 音量・BGMの有無・台詞の間 | report の5章 |
| 話す速さ | report の6章（字幕から文字/分） |
| 動画全体のリズム | `images/timeline.png`（転換・動き・音量・各領域を時間軸に並べた図） |

## Step 0: 準備（初回だけ）

```powershell
# Windows (PowerShell)
py -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

```bash
# Mac/Linux/クラウド
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

YouTubeから取得する場合は **Node.js か Deno のどちらか**も必要（YouTube側の暗号を
解くのに使われる）。AITuberKitのためにNode.jsを入れていればそれで足りる。

## Step 1: チャンネル全体を把握する

```powershell
.venv\Scripts\python scripts\analyze_video.py channel https://www.youtube.com/@toshiusagi
```

`analysis/channel_toshiusagi/channel_report.md` に、動画の長さの分布・再生数トップ10・
タイトルの傾向（【】や？の使用率、よく使う【】の中身）・サムネ一覧・
**分析候補（再生数上位3本＋最新）とそのコマンド**が出る。まずはここから1〜3本選ぶ。

## Step 2: 動画をフレーム分析する

```powershell
.venv\Scripts\python scripts\analyze_video.py video https://www.youtube.com/watch?v=動画ID
```

- 出力先は `analysis/<動画ID>/`。`report.md` を開けば全体が分かる
- 処理時間の目安: 15分の1080p動画で5〜15分（PC性能による。最大1080pで取得）
- 長い動画は `--max-minutes 5` で先頭だけ分析できる
- 自分で録画した動画（OBSの録画など）も分析できる:
  `... video 録画.mp4`（字幕ファイルがあれば `--subs 字幕.vtt`）

主なオプション:

| オプション | 既定 | 意味 |
|---|---|---|
| `--interval` | 10 | 定間隔フレーム一覧の間隔（秒） |
| `--strips` | 12 | 連番フレーム（ストリップ）の枚数 |
| `--max-keyframes` | 120 | 場面ごとのキーフレームの上限 |
| `--max-height` | 1080 | ダウンロード画質の上限 |
| `--cookies-from-browser` | なし | ボット確認で止まった時だけ（下記） |

## Step 3: 画像を見て「制作仕様書」にする（Claudeに頼む）

ローカルのClaude Codeにこう頼む（コピペ用）:

```
analysis/<動画ID>/report.md と images/ の画像を全部見て、
docs/06 の目視チェックリストの項目を1つずつ埋めて、
自分の動画で再現するための制作仕様書を docs/07_style_spec.md にまとめてください。
数値はreportの値を使い、推定の部分は推定と書いてください。
```

複数本を分析したら「共通している点」と「動画ごとに違う点」を分けてまとめてもらうと、
そのチャンネルの“型”が見える。

## 数値の意味

| 用語 | 定義（scripts/analyze_video.py の定数） |
|---|---|
| 変化した画素 | 前フレームとのRGB差のどれかが **20** を超えた画素（横480pxに縮小して判定） |
| 動きのあるフレーム | 画面の0.2%以上の画素が変化、または画素差の平均が1.2以上 |
| イベント | 動きのあるフレームのかたまり（1フレームの途切れは同じイベント扱い） |
| 場面転換 | イベントの前後で画面の **15%以上** が入れ替わったもの |
| 全面カット / 全面トランジション | 前後で **50%以上** が、1〜2フレームで / 3フレーム以上かけて変わったもの |
| アニメーション付きの変化 | 3フレーム以上続いたイベント（ポップイン・スライド・拡大・揺れなど） |
| 領域 | 1分に1回以上変化する場所をセル（解析画像で12px角）単位でまとめたもの |
| まとまり（バースト） | 領域の変化が0.4秒未満の間隔で続くものを1つにまとめたもの。口パクなら1台詞、まばたきなら1回 |
| 間（ま） | 音量が「発話の大きさ」と「背景の大きさ」の中間を0.15秒以上下回った区間 |
| 統合ラウドネス | 動画全体の平均的な音の大きさ。YouTubeは-14 LUFSを基準に再生音量を揃える |

領域の「推定」（字幕帯?・口パク?・まばたき?など）は位置・形・頻度からの**当て推量**。
必ず連番ストリップや一覧シートで目視確認すること。

### 精度について（合成動画で検証済み）

`tests/run_video_selftest.py` が、正解の分かっている合成動画（図形だけのキャラ2体・字幕帯・
ポップイン・カット・クロスフェード・口パク・まばたき・台詞の間）で検出結果を照合している。
先頭に0.1秒のずれがある動画でも、切り出したフレーム番号が1フレームも狂わないことを確認済み。

既知の限界:

- 圧縮ノイズ（キーフレーム前後の輪郭のちらつき）を拾わないよう、差が20未満の変化と
  1フレームだけで消える変化は数えない。そのため、ごく淡い変化（薄い影の揺れ等）は拾わない
- 同時に起きた変化は1つのイベントにまとまる。主な変化の範囲（main_bbox）は、同時に起きた
  小さな変化（口パク等）と開始フレームだけの変化（字幕差し替え等）を除いて求めている
- 解析は横480px。1080p素材の口パクや字幕の文字替わりは拾えるが、数ピクセルの動きは拾わない
- 話速は自動字幕（音声認識）からの概算。誤認識を含む

## 目視チェックリスト（画像を見て埋める）

**レイアウト**（median_layout / keyframes）
- キャラの位置・大きさ（画面高さの何%）、何人いるか
- 字幕枠の位置・大きさ・背景（帯/吹き出し/枠なし）
- 図解エリアの位置・大きさ、話題タイトルの常時表示の有無

**字幕（テロップ）**（interval一覧・字幕帯のストリップ）
- フォントの系統（丸ゴシック/角ゴシック/手書き風）、文字の高さ（画面高さの何%）
- 縁取り（色・太さ・二重縁の有無）、話者ごとの色分け
- 1枚あたりの行数・文字数、強調（色替え・拡大）の頻度
- 出方（瞬時／フェード／ポップ）と差し替え間隔（report 3章）

**キャラクター**（口パク・まばたきのストリップ）
- 口パクの枚数（開閉2枚か、中間の口もあるか）と切替間隔
- まばたきの間隔と長さ、表情差分の数、話す時の跳ね・揺れなどの動き

**図解・素材**（anim ストリップ・keyframes）
- 種類（グラフ/表/アイコン/写真/イラスト）、出現アニメの種類と長さ（フレーム数）
- 強調の手法（赤枠・マーカー・拡大・矢印）

**転換・演出**（cut / transition ストリップ・timeline）
- カットとトランジションの比率、トランジションの種類と長さ
- 章の区切り方（タイトルカード・効果音・背景の変化）

**色**: 背景色・アクセント色・全体のトーン（median_layout から拾う）

**音**（report 5・6章）
- 音量（LUFS）、BGMが常時鳴っているか、台詞の間の長さ、話速（文字/分）
- 効果音の頻度（timeline の audio 列の鋭いピーク＋該当箇所を再生して確認）

**構成**（chapters・timeline・interval一覧）
- 冒頭の何秒で本題に入るか（つかみ）、章立て、締め（まとめ・次回予告・登録誘導）

**サムネイル**（channel の thumbs_top / thumbs_recent）
- 文字数・文字の大きさ・配色、キャラの表情、レイアウトの型

## 実行環境ごとの注意

- **このリポジトリのクラウド環境（Claude Code on the web）**: 環境の Network access で
  `youtube.com` `*.youtube.com` `*.googlevideo.com`（動画本体の配信元）`*.ytimg.com`（サムネ）
  を許可する必要がある（2026-09-25時点では未許可で、取得はブロックされる）。
  許可してもYouTubeがクラウドのサーバーを「ボット確認」で止めることがあり、その場合はPCで実行する
- **自分のPC**: そのまま動く。「Sign in to confirm you're not a bot」で止まった時だけ
  `--cookies-from-browser edge`（または chrome / firefox）を付ける。自分のブラウザの
  ログイン情報を使うため、**自分のPCでだけ**使うこと（クラウドには入れない）

## 権利・マナー（重要）

- 真似してよいのは**技法**（テンポ・レイアウトの考え方・字幕の読みやすさの工夫・音量バランス）。
  見せ方のアイデア自体は著作権で保護されないが、**キャラクターの絵・台本・サムネの絵柄・BGM**
  などの表現そのものは使わず、オリジナルで作る
- ダウンロードした動画・切り出したフレーム・字幕の書き起こし（transcript.txt）は**分析用**。
  `analysis/` はgit管理外にしてあるので、コミット・共有・再配布しない
- YouTubeの利用規約は原則として動画のダウンロードを認めていない。分析は自分の手元に限り、
  自己責任で行うこと
