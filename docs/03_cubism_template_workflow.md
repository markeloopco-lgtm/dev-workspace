# 03. Cubism取り込みとテンプレート量産ワークフロー

正規化PSD（`output/*_normalized.psd`）をLive2D Cubism Editorに取り込み、
**1体目だけ丁寧にリグを作り、2体目以降はテンプレート適用＋微調整**で量産する。

## 前提

- Live2D Cubism Editor **PRO版**（FREE版はレイヤー数・機能制限で実運用不可。
  PROは月額/年額/3年一括。学生・小規模事業者向け割引あり）
- 正規化PSDは全モデルで同一のフォルダ構成・レイヤー名になっている
  （これがテンプレート機能の対応付け精度を決める）

## 1体目: マスターモデルを作る（ここだけ時間をかける・目安1〜2日）

1. Cubism Editorに正規化PSDをドラッグ＆ドロップ（レイヤーがそのままアートメッシュになる）
2. メッシュの自動生成 → 顔まわりだけ手動で密度を上げる
3. パラメータ設定（最低限のセット）:
   - 角度X / 角度Y / 角度Z（顔の向き・傾き）
   - 目 開閉L/R、目玉X/Y、眉 上下
   - 口 開閉・変形（あ・い・う・え・お対応にするとリップシンク品質が上がる）
   - 体の回転X/Z、呼吸
4. 物理演算: 髪（前・横・後）と胸・アクセサリに振り子を設定
5. まばたき・呼吸の自動アニメーション設定
6. **このモデルを「テンプレート」として保存**（.cmo3をテンプレフォルダに保管）

## 2体目以降: テンプレート適用（目安1〜2時間/体）

1. 新しい正規化PSDをCubismで開く
2. メニュー **「ファイル → テンプレートを適用」** → 1体目の.cmo3を選択
3. レイヤー名が一致しているため、メッシュ・変形・パラメータ・物理設定が自動転写される
4. 微調整チェックリスト:
   - [ ] 目・口の開閉が破綻していないか（最優先。輪郭差で崩れやすい）
   - [ ] 前髪の物理の揺れ幅
   - [ ] 角度X/Yを最大まで振って輪郭の破れ確認
   - [ ] テクスチャアトラス生成（2048px推奨）
5. 組み込み用書き出し: **.moc3 + model3.json** 一式

## 書き出したモデルの使い先

| 用途 | ツール |
|---|---|
| 配信（手動トラッキング） | VTube Studio（Webカメラ対応・Steam無料） |
| 配信（AITuber自動運用） | AITuberKit（Live2D表示対応。チャット応答・音声合成と統合） |
| 動作確認 | Cubism Viewer（SDK同梱） |

AITuberKitに組み込めば、前に設計した「Geminiでチャット返信生成 → Style-Bert-VITS2で
音声合成 → 口パク連動 → OBS配信」の自動運用構成にそのまま載る。

## 量産スループットの目安

| 工程 | 1体目 | 2体目以降 |
|---|---|---|
| 一枚絵（外部） | 外注リードタイム | 同左 |
| See-through分解＋正規化 | 数分（自動） | 数分（自動） |
| Cubismリギング | 1〜2日 | **1〜2時間** |

## ライセンス覚書

- Cubism Editor PROで作った.moc3の商用利用は、事業規模により
  「出版許諾契約」が必要になる場合がある（小規模なら不要枠あり。公式の最新条件を確認）
- モデル販売時は一枚絵の権利者との契約範囲（再販許可）を再確認すること
