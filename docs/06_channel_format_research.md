# 06. 海外フォーマットの日本輸入リサーチ（非属人YouTube）

調査日: 2026-08-27 / 対象: 海外で成長中の「非属人（フェイスレス）」YouTube フォーマットのうち、
日本語圏にまだ competitor がいないもの。

---

## 0. 結論（先に読むところ）

**「日本にないジャンル」を探しても、もうほとんど残っていません。空いているのは "ジャンル" ではなく "品質レイヤー" と "視聴者層" です。**

日本の非属人 YouTube は、ほぼ全ジャンルが **ゆっくり解説／ずんだもん解説** に埋め尽くされています。
つまり日本では「非属人 ＝ 合成音声＋静止画スライドの量産テンプレ」とほぼ同義になっており、

- その形式が **2026年の YouTube 収益化厳格化で直撃を受けている**（後述 §1）
- その形式が刺さる視聴者は **10〜40代の男性・オタク寄り** に偏っている
- 一方で日本最大の視聴者層である **50歳以上（人口の半分超）** 向けの非属人チャンネルはほぼ空白

この3つが重なった場所が、いま日本で唯一まとまって空いている穴場です。

**本命3案（詳細は §4）**

| # | 案 | ひとことで | 日本の競合 |
|---|---|---|---|
| A | 手間をかけた日本語ドキュメンタリー解説 | 海外の MagnatesMedia 型を「ゆっくり以外」でやる | ほぼ不在（同需要はゆっくりが占有中、かつそれが崩れつつある） |
| B | シニア（60代〜）向け 非属人チャンネル | 世界一の高齢社会なのに非属人コンテンツが無い | 属人（顔出し）チャンネルばかりで非属人はほぼ空白 |
| C | 【番外・逆輸出】Live2Dキャラによる海外向け日本語/日本文化 | 輸入より輸出のほうが穴が大きい。手持ち資産と完全一致 | 実質ゼロ |

## 1. 先に地雷原を確定させる（ここを外すと全部無駄になる）

穴場探しの前に、2026年時点で **やった瞬間に詰む** 条件を確定させます。

### 1-1. YouTube「不正直なコンテンツ（inauthentic content）」3類型

2025年7月15日に「繰り返しの多いコンテンツ」ポリシーが *inauthentic content* に改称され、
2026年7月16日にさらに内訳が明確化されました。収益化できないのは次の3つ:

1. **汎用的・反復的・テンプレ的なコンテンツ** — AI や定型テンプレで作った、ほぼ同一の動画で埋まったチャンネル
2. **不快・扇情的なコンテンツ** — 視聴者を感情的に煽るだけのもの
3. **AIペルソナが「健康・金融・法律」など繊細な話題を語るもの** — 例: AI の「医師」が健康アドバイスをする、AI のポッドキャスト司会者が投資助言をする

違反が数本あるだけで **チャンネル全体** の収益化が剥がれる可能性があり、
剥がれた場合の再申請は **90日後**（その時点の内容で再審査）。

> **この3番目が、このプロジェクトに直撃します。**
> Live2D キャラ（＝AIペルソナ）に健康・お金・法律を語らせる企画は、
> どれだけ内容が正しくても収益化されません。**健康系・お金系は Live2D キャラで喋らせない。**
> やるなら「キャラなしのナレーション＋図解」に形式を切り替えること。

なお YouTube は「AI を使うこと自体は収益化に影響しない」と明言しています。
禁じられているのは *ツール* ではなく *量産・テンプレ・低労力* です。

### 1-2. 日本国内の「収益化停止祭り」

2026年、日本でも **ゆっくりボイス／ずんだもん ＋ 静止画スライド** のテンプレ動画が
広範囲に収益化停止された、という報告が複数出ています（AI合成音声そのものが禁止されたわけではない）。

つまり **日本の非属人チャンネルの主流フォーマットが、いま制度的に崩れつつある**。
これは新規参入者にとってはリスクではなく **空白の発生** です。§4-A の根拠がこれです。

### 1-3. 日本固有の法務地雷: 漫画・映画・アニメの「要約 / recap」

海外の非属人チャンネルでいま最も伸びているジャンルのひとつが
**manhwa / webtoon / アニメの recap（ネタバレ要約）** ですが、**日本では輸入不可** です。

- 2021年11月、仙台地裁が「ファスト映画」投稿者3名に **有罪判決**（主犯格に懲役2年・罰金200万円・執行猶予4年）
- 「ネタバレが全部ダメ」ではなく、原著作物の **創作的表現への依拠性・類似性** があるとアウト
- 要約であっても、あらすじを追う形式は依拠性が認められやすい

日本の権利者団体は海外より遥かに執行が積極的です。**このジャンルは検討リストから外してください。**

## 2. なぜ日本に「穴」ができるのか（構造の説明）

| 事実 | 出典の要旨 |
|---|---|
| 2025年、日本は **50歳以上が人口の半数を超えた** 史上初の国になった | シニア調査 |
| **50歳以上の女性の85%** が普段 YouTube を視聴している | ハルメク調査 |
| その視聴ジャンル1位=**料理**、2位=**コンサート/ライブ映像**、3位=**健康・医療** | 同上 |
| 米国のシニアは **テレビ画面** で見るが、日本のシニアは **スマホ中心** | 日米比較 |
| 日本の非属人フォーマットは **ゆっくり解説／ずんだもん** に極度に集中 | 国内解説記事 |

**噛み合っていない点：**
日本最大の視聴者ブロック（50歳以上）と、日本の非属人フォーマット（ゆっくり／ずんだもん）は
**対象年齢も語り口もまったく合っていません**。ゆっくり音声はシニアには聞き取りづらく、
ネットミーム前提の話し方も刺さりません。

結果として、日本のシニア向けチャンネルは **属人（顔出しの先生・おじいちゃん/おばあちゃん本人）** ばかりで、
**非属人で量産できるシニア向けチャンネルという層が丸ごと空いています**。
海外ではここが「senior storytelling」「life lessons」として明確に伸びている領域です。

## 4. 本命3案の詳細

### 本命A — 手間をかけた日本語ドキュメンタリー解説

**狙い**: ゆっくり解説が制度的に崩れたあとの空白を取る。

- **海外の型**: MagnatesMedia（185万人）、Company Man、Fascinating Horror、Business Casual
  共通構造 = 「◯◯はなぜ崩壊したのか」＋ストック映像＋落ち着いたナレーション＋出典明記
- **なぜ日本で空いているか**: 同じ需要（企業史・産業史・事故・事件の解説）は日本にも大量にあるが、
  供給がほぼ全部ゆっくり／ずんだもんで、**声とテンポが「まじめなドキュメンタリー」に合っていない**
- **差別化点**: Style-Bert-VITS2 の自然な合成音声を使い、静止画スライドではなく
  図解・年表・出典スクリーンショットで構成する。1本30分・週1本。**量産しない**ことが最大の防御
- **規約上の注意**: 「投資助言」「儲け方」に踏み込むと AIペルソナ×金融の禁止類型に接近する。
  あくまで **過去の出来事の記録** として構成し、視聴者への助言を含めない
- **RPM 参考値（日本）**: 全体で1000再生あたり100〜200円、ビジネス・金融・不動産系は800〜2500円

### 本命B — シニア（60代〜）向け 非属人チャンネル

**狙い**: 世界一の高齢社会で、非属人フォーマットだけが空いている場所を取る。

- **やる**: 「昭和のあの頃」「消えた商店街」「昔の道具の使い方」「スマホ・行政手続きのやさしい解説」
- **やらない**: 健康・医療（AIペルソナ禁止類型）、年金・相続（同じく金融）、体操（すでに激戦）
- **形式要件**:
  - 話速をゆっくり、字幕は大きく、色コントラストを強く（スマホ視聴が主流のため）
  - ゆっくりボイスは使わない。落ち着いた合成音声か人間ナレーション
  - サムネの文字を大きく
- **素材の壁**: 昭和の映像・写真は権利が厳しい。**自作イラスト／フリー素材／自分で撮った現在の風景** に限定すること
- **注意**: 日本のシニアは購買力があり、YouTube 経由の購買経験も約50%あるという調査がある一方、
  広告単価は分野依存。実用系に寄せると単価が上がる

### 本命C（番外） — 逆輸出: Live2Dキャラ × 海外向け日本語コンテンツ

**「輸入」の依頼から外れますが、手持ち資産に対して最も穴が大きいのでここに書きます。**

- 海外の語学系は Comprehensible Input（理解できる範囲の入力だけを浴びる）方式が確立し、
  Dreaming Spanish はこの方式でアプリが TIME の 2025年ベスト発明に選ばれるまで成長
- **日本語版の同等物はほぼ存在しない**。しかも作れるのは日本語ネイティブだけ
- Live2D キャラがゆっくり日本語で日常を話す → 顔出し不要・属人性ゼロ・キャラが資産になる
- 視聴者が英語圏になるため、**日本向けの5〜10倍の広告単価**が期待できる
- 規約面: 語学は「繊細な話題」に該当しないため、AIペルソナ制限にかからない

## 5. 最初の30日でやること

1. **week 1 — 検証**: 下の §6 の手順で、A/B の候補キーワードを10個ずつ実測。
   「上位が全部ゆっくり」なら本命Aの狙い目、「上位が全部顔出し」なら本命Bの狙い目
2. **week 2 — 1本作る**: 一番手応えのあったテーマで30分尺を1本。台本→音声→図解の順
3. **week 3 — 3本目まで**: フォーマットを固定。サムネのA/Bを試す
4. **week 4 — 判断**: 3本の平均視聴維持率が **30%を超えているか** だけを見る。
   登録者数はこの時点では見ない

**撤退基準**: 10本出して平均視聴維持率が25%を切るなら、テーマではなく**形式**が合っていない。

## 6. 自分で穴場を検証する手順（今後も使える）

1. YouTube で候補キーワードを検索 → フィルタ「今年」「動画」
2. 上位20本の **チャンネル登録者数** をメモ。1万人未満のチャンネルが10万再生を取っていたら**需要 > 供給**のサイン
3. 上位が **全部ゆっくり／ずんだもん** なら「形式の穴」がある
4. 上位が **全部顔出し** なら「非属人の穴」がある
5. 上位が **大手メディア・テレビ局** なら撤退（勝てない）
6. 同じキーワードを英語にして検索し、**海外に100万再生級があるのに日本に無い** なら輸入候補

## 8. この調査の限界（正直に）

- 「日本に競合がいない」の確認は、日本語 Web 検索と業界記事にもとづく**推定**です。
  YouTube 全チャンネルを機械的に走査したわけではありません。§6 の手順で必ず自分の目で確認してください。
- 海外フェイスレス系の情報は**アフィリエイト目的の低品質記事が大量に存在**します。
  本文中の RPM やチャンネル数の数値は、そうした記事由来のものは採用せず、
  一次情報に近いもの（公式ポリシー、報道、調査会社のプレスリリース、判例報道）を優先しました。
- 広告単価は時期・季節・視聴者層で大きく変動します。表の数値は桁感の目安です。
