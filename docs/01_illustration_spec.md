# 01. 一枚絵の仕様（外部発注・外部生成用）

一枚絵はこのパイプラインの唯一の外部入力。ここの品質と構図の統一が
後工程（See-through分解精度・Cubismテンプレート流用率）を直接決める。

## 必須要件

| 項目 | 要件 | 理由 |
|---|---|---|
| 形式 | PNG（透過推奨）または単色背景 | 分解精度が上がる |
| 解像度 | 長辺 **2048px以上**（最低1280px） | See-throughは1280pxで処理する |
| 人数 | 1キャラのみ | 複数人は分解が破綻する |
| 向き | 正面〜やや斜め（15度以内） | テンプレリグの流用前提 |
| 構図 | バストアップ〜膝上。**全モデルで統一する** | テンプレ適用の成功率に直結 |
| 腕 | 顔・胴体に重ねない（下ろす or 軽く開く） | オクルージョン補完の負荷を減らす |
| 塗り | アニメ塗り／セル塗り系 | 厚塗り・水彩は分解が乱れやすい |

## 避けるもの

- 極端に複雑な小物（武器、楽器、大きな翼など）→ レイヤー分解が乱れる
- 顔にかかる大きな装飾（眼帯・マスク等）→ 表情リグが作れない
- 強いパース・俯瞰・あおり構図
- フレーム外に見切れる重要パーツ

## 発注テンプレ（コピペ用）

```
【用途】Live2Dモデル化（改変を含む）に使用します。
【必須許諾】納品物のLive2D化・パーツ分割・加筆修正の許可をお願いします。
【仕様】
- 1キャラ、正面向き（傾き15度以内）、バストアップ
- 腕は体の横に下ろした状態（顔・胴に重ねない）
- アニメ塗り、背景透過PNG、長辺2048px以上
- レイヤー統合済みの一枚絵で構いません（分解はこちらで行います）
```

## 権利まわりの注意

- **外部絵師に発注する場合**: 「Live2D化・改変OK」の許諾を契約に必ず明記する。
  許諾のない一枚絵のLive2D化は著作権侵害になり得る。
- **AI生成画像を使う場合**: 生成サービスの利用規約（商用利用・改変可否）を確認する。
  また、モデル販売先（nizima等）はAI生成作品の取り扱いポリシーが
  変わることがあるため、販売目的なら出品前に最新の規約を確認すること。
- 配信プラットフォームのAIコンテンツ開示ポリシー（YouTubeの合成メディア開示等）にも留意。

## 量産のコツ

シリーズで量産するなら、**キャラデザだけ変えて構図・ポーズ・画角を完全固定**する。
1体目で作ったリグ（変形・物理・パラメータ）の流用成功率が大きく変わる。
