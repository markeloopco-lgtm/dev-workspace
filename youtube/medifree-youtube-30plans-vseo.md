## 0. 最初に：VSEOで一番大事な考え方

**結論：新規チャンネルはビッグキーワードで勝てません。**

「看護師 辞めたい」は月間検索が最大級ですが、YouTubeで検索すると
転職サイト（看護roo!、レバウェル看護等）の公式チャンネルと登録者10万人級が並びます。
ここに1本目を出しても、誰にも届きません。

**正しい順番はこうです。**

```
第1期：競合が薄いロングテール（開業届・確定申告・案件の探し方）で
       「検索して上位に出る」実績を作る
        ↓ チャンネルの評価が溜まる
第2期：中間キーワード（フリーランス看護師・企業看護師・在宅ワーク）を取る
        ↓ 登録者と視聴維持率が付く
第3期：ビッグキーワード（看護師 辞めたい・副業）に殴り込む
```

### もう一つ、前提として知っておくこと

YouTubeの再生の大半は**検索ではなく「関連動画・おすすめ表示」**から来ます。
VSEOだけでは伸びません。役割分担はこうです。

| 手段 | 役割 | 効き方 |
|---|---|---|
| **VSEO（検索対策）** | 細く長く、確実に刺さる人が来る | 半年〜2年、放置でも再生される**資産** |
| **ショート動画** | 一気に認知が広がる | 瞬発力はあるが数日で止まる |
| **サムネ・タイトル訴求** | 関連動画から拾われる | 中期。維持率が良いほど回る |

集客チャンネルにとってVSEOが重要な理由は、**検索から来た人は悩みが明確で、
LINE登録率が段違いに高い**からです。再生数は少なくても構いません。

## 1. VSEOの実装ルール（全動画共通）

YouTubeのアルゴリズムは、タイトル・概要欄・タグ・字幕といったメタデータを解析して
検索クエリとの関連性を判断します。つまり**書いた文字が全て**です。

### ① タイトル
- **全角32文字以内**。それ以上はスマホで切れます
- **メインキーワードは必ず左詰め**（先頭〜15文字以内）
- 【】の装飾は入れてよいが、**【】の中にもキーワードを入れる**
  - ❌ 【必見】フリーランス看護師の話
  - ⭕ 【全公開】フリーランス看護師の収入とリアルな1ヶ月
- 疑問形（〜とは？／〜は？）は検索クエリと一致しやすく有利

### ② 概要欄
- **最初の2〜3行が検索結果のスニペットに出ます**。ここが最重要
- 1行目にメインキーワードを自然に含んだ説明文
- 2行目以降にサブキーワードを散らした本文（300〜500文字）
- その後にチャプター → LINEリンク → 関連動画 → ハッシュタグ3個
- ※ 前資料では「1行目にLINEリンク」と書きましたが、**VSEOを優先するなら
  1行目は説明文、LINEリンクは4〜5行目**に変更してください。
  クリックを取りたいリンクは**固定コメント**に置くのが両立策です

### ③ タグ
- **5〜10個**が目安。詰め込みすぎは逆効果
- 構成：メインKW／表記ゆれ（ひらがな・カタカナ・英字）／関連KW／ジャンル名
- 例：`フリーランス看護師` `ふりーらんす看護師` `看護師 フリーランス` `看護師 働き方` `看護師 転職` `看護師 副業` `ナース` `看護師 病院以外`

### ④ チャプター（タイムスタンプ）
- **4〜6個**必ず入れる。視聴者が見たい所に飛べて離脱が減ります
- チャプター名にもキーワードを入れる（`03:12 フリーランス看護師の1ヶ月の収入`）
- 0:00 から始めること（そうしないと機能しません）

### ⑤ 字幕
- 自動字幕がそのままメタデータとして読まれます
- **はっきり、少しゆっくり話す**。専門用語は必ず口頭でも言う
- 冒頭30秒でメインキーワードを**口に出して2回**言う（これが効きます）

### ⑥ その他
- アップロードするファイル名を `kangoshi-yametai-sentakushi.mp4` のようにローマ字KWにする
- サムネの文字とタイトルは**別の言葉**にする（情報量が2倍になる）
- Google検索にも動画を出したいなら「〜のやり方」「〜の手順」「〜比較」系が有利

## 2. サジェスト連携（実データでこの企画表を上書きする）

**この企画表のキーワードは「推定」です。実データで裏を取ってください。**
そのためのツールを `youtube/tools/` に用意しました。詳細は `youtube/tools/README.md`。

### 手順（Mac：ダブルクリック1回）

`youtube/tools/run_mac.command` をダブルクリックして、聞かれたら
`1`（お試し・1〜2分）→ うまくいったら `2`（本番・15〜25分）を選ぶだけです。

収集からレポート生成まで自動で走り、2つのファイルができます。

- `youtube/keywords/suggest.csv` … 集めたサジェスト
- `youtube/keywords/report.md` … 企画30本との突き合わせレポート

**この2つを渡してもらえれば、30本のタイトルを
実際に検索されている言い回しに書き直します。**

コマンドで回す場合:

```bash
python3 suggest_kit.py fetch --seeds seeds.txt --out ../keywords/suggest.csv
python3 suggest_kit.py match --suggest ../keywords/suggest.csv \
    --plans ../keywords/plan_keywords.tsv --out ../keywords/report.md
```

レポートには3つの表が出ます。

1. **企画ごとのサジェスト裏付け** — ヒット数0の企画＝**誰も検索していない言葉**。要修正
2. **カバーできていない検索需要** — 30本に無い検索語を需要順に。企画追加の候補
3. **需要が大きいサジェストTOP50** — 公開順の優先度を決める材料

### ツールで取れないもの（手作業が必要）

- **検索ボリュームの実数**：Googleキーワードプランナー（Google広告アカウント作成のみで無料）
- **競合の強さ**：YouTubeでそのKWを検索し、**上位10本の登録者数**を見る
  - 1万人以下のチャンネルが3本以上 → **勝てる。今すぐ狙う**
  - 全部10万人以上 → 後回し
- **伸びている動画の型**：フィルタを「今月」に絞り、再生数が伸びている動画を観察

## 7. 公開後にやるVSEO（ここを9割の人がサボります）

1. **公開2週間後**、YouTube Studio →アナリティクス→リサーチ→
   「視聴者が検索している語句」を見る
2. そこに**自分が想定していなかったKW**が出ていたら、
   **タイトルと概要欄を書き換える**（動画は消さない。何度でも直せます）
3. インプレッションのクリック率が**4%を下回っていたらサムネを変える**
4. 平均視聴維持率が**30%を切っていたら冒頭30秒を作り直す**（再アップではなく次回に反映）
5. 伸びた動画の関連動画に自分の別動画が出るよう、**終了画面と概要欄で内部リンク**を張る
