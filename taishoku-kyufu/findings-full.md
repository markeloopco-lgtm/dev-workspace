## 発見1（最重要）：「退職給付金」は全然ちがう意味で検索されていた

私は「業者が作った呼称で、ネガティブ検索が増えている」と想定していました。**外れです。**

実際のサジェスト上位はこうでした。

```
退職給付金 計算（20） / 退職給付金 パート（20） / 退職給付金 とは（20）
退職給付金 退職前（19） / 退職給付金 自己都合（19） / 退職給付金 受け取り方（19）
退職給付金 定年退職（19） / 退職給付金 税金（16） / 退職給付金 条件（16）
```

**「定年退職」「受け取り方」「税金」「計算」** ——
これは会計用語の **「退職給付」（＝退職金・退職給付会計）** を調べている人たちです。

つまり「退職給付金」で上位を取っても、**来るのは退職金の額を調べている人**。
サポートを求めている人ではありません。2,714点は**完全に的外れなトラフィック**です。

→ 結論は変わりません。**この語は使わない。** ただし理由は
「炎上リスク」ではなく「**そもそも客が来ない**」でした。

## 発見2：業者を探す検索は、ほぼ存在しない

```
社会保険給付金サポート   105点（11語）
傷病手当金 サポート       61点（7語）
```

失業保険5,118点に対して**50分の1以下**。しかも中身がこれです。

```
社会保険給付金サポート 怪しい（10）  ← 2番目に出てくる
社会保険給付金サポート とは（10）
社会保険給付金サポート 口コミ（7）
```

**指名検索で取れる市場は存在しません。** サービス名で待っていても誰も来ない。
**制度の検索から拾いにいくしかない**、というのが実測の結論です。

## 発見3（戦略級）：「退職後の手続き」が最大の集客資産だった

私はここをTier B（信頼構築用）と評価していました。**過小評価でした。**

```
任意継続            3,136
扶養に入る          2,556
国民健康保険 減免    2,295
退職後 健康保険      1,772
住民税 退職後        1,390
─────────────────────────
合計               11,149点
```

**制度本体（失業保険5,118＋傷病手当金4,405＝9,523点）より大きい。**

しかも中身が具体的で、答えが1つに決まる質問ばかりです。

```
任意継続 国保 どっちが安い（12）
国民健康保険 減免 離職コード 33（10）
退職後 健康保険 14日過ぎた（15）
退職後 健康保険 安くする方法（10）
扶養に入る 失業保険（12）
```

**退職した全員が必ず通る道で、全員が困っている。**
ここを押さえると「退職後のことは全部この人に聞けばいい」という位置が取れます。
給付金の相談は、その延長線上で自然に発生します。

## 発見4：「傷病手当金」の最大の関心は「働けるか」

```
傷病手当金 アルバイト（20） / バイト（20） / パート（20） / 役員（20）
傷病手当金 再発（20） / 2回目（20）
傷病手当金 少ない（20）
傷病手当金 つわり（20）  ← 妊娠セグメント
```

- **受給中に働けるのか** が最大の不安（アルバイト・バイト・パート・役員で4語）
- **再発・2回目** ＝ 一度受給した人の再受給。リピート需要がある
- **つわり** ＝ 妊娠・切迫流産のセグメント。**完全に想定外の市場**でした
  （「切迫流産 休職 給料」も別シードで出現）

## 発見5：「退職代行」が失業保険と同格（5,055点）

ここも過小評価でした。ただし中身を見ると様子が違います。

```
退職代行 モームリ（20） / EXIT（20） / イグジット（20）
退職代行 フォーゲル（20） / real value（20）
```

**すでに固有名詞（ブランド）の勝負になっています。** 新規が正面から入る場所ではない。

一方で情報系も残っています。

```
退職代行 デメリット（19） / 流れ（19） / 労働組合（20）
退職代行 40代（20） / 30代（20） / 漫画（20）
```

→ **提携・送客の相手として最高。** 退職代行を使う人は、
そのまま給付金の対象者です。同じ人が同じ時期に検索しています。

## 発見6：職業別は「公務員・教員」が圧倒的。ただし要注意

```
公務員 休職    2,521点
教員 休職      1,622点
────────────────────
合計           4,143点

看護師 うつ      242点
保育士 適応障害   222点
介護士 退職      182点
```

**私は看護師を本命に挙げましたが、公務員・教員の17分の1しかありませんでした。**

### ⚠️ ただし、公務員・教員はサービス対象にならない可能性が高い

サジェストの中身がこうです。

```
公務員 休職 給料（13） / 手当（10） / ボーナス（13） / 3年（13）
公務員 休職 通算 リセット（10）
```

公務員は健康保険が**共済組合**で、しかも**休職中も給与の一定割合が支給される**制度です
（分限休職）。つまり**傷病手当金のスキームがそのまま当てはまりません。**

→ **需要は巨大だが、収益化できない層かもしれない。**
　 ここに投資する前に、**自社サービスが公務員・教員を受けられるか確認してください。**
　 受けられないなら、4,143点は取っても無駄になります。

## 発見7：私の「狙い目」予測が2つ外れました

当初「誰も書いていない極薄の狙い目」として挙げた2つです。

| キーワード | 予測 | 実測 |
|---|---|---|
| 休職 保険料 引かれる | ★狙い目 | **224点**（29シード中24位） |
| 休職 生活費 | ★狙い目 | **214点**（26位） |

**競合が薄いのは、需要が小さかったからでした。**
「知らないと損する話だから刺さるはず」という推測は、検索行動には現れていません。

ただし語としては実在します（`休職 保険料 いくら` `休職 中 の 生活費` `休職 生活費 足りない`）。
**単独の記事にはせず、大きい記事の中の1セクションとして扱う**のが正解です。

```
適応障害 休職 罪悪感（20）   ← 感情。ここが一番深い
適応障害 休職 労災（20）      ← 労災という別ルートを探している
適応障害 休職 延長 / 1ヶ月 / 半年 / 期間（各18〜20）  ← 期間の不安が中心
鬱 休職 復帰（20） / 転職（16） / 退職（16）
```

「お金」より **「いつまで休めるのか」「復帰できるのか」「休むことへの罪悪感」**
が上位に来ています。当初想定の「症状×お金」より、**症状×期間×罪悪感**が実態でした。
