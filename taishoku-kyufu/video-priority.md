## ⚠️ 先に確認してほしいこと

**今のデータはYouTubeとGoogleの合算です。**
制度系（傷病手当金・任意継続・特定理由離職者）は**Google偏重の可能性が高い**。
休職中の人は動画より記事を読むからです。

**YouTubeでは3語しか返ってこなかった**という事例がありました。同じ罠があります。


下の順位は合算データに動画適性を掛けた暫定版です。YouTube側が薄いテーマは
記事に回す判断になるので、実行前に一度回してください。

## 順位の付け方

```
需要スコア（実測） × 動画適性 × 競合の薄さ × 成約距離
```

### 動画適性の基準

| ◎ 動画向き | × 記事向き |
|---|---|
| 書類・画面を見せられる（申請書、離職票、計算） | 自治体ごとに違う数字 |
| 時系列で追える（手続きの流れ） | 網羅的な条件の列挙 |
| 判定できる（チェックリスト） | 細かい例外規定 |
| 感情に触れる（体験談・共感） | 出典の多い解説 |

動画で線引きを示すと、そのまま「自分の場合はどうか」の相談に流れます。

## ショート専用（長尺にしない）

感情ワードは需要が大きく見えますが、**ノイズが多く、成約が遠い**。
認知目的でショートに限定します。

```
会社 行きたくない（20）   ※「飲み会 行きたくない」等が混在
仕事 涙が出る（18）        ※「涙袋」等が混在
出社拒否（20）
退職 貯金（20）
```

長尺の切り抜きで回すのが最も効率的です。

## 記事に回すもの（動画にしない）

| テーマ | 理由 |
|---|---|
| 国民健康保険 減免の自治体別 | 熊本市・足立区など地域語が多く、動画1本にまとまらない |
| 扶養に入る条件の網羅 | 例外が多く、読み返す必要がある |
| 失業保険の認定日・説明会の手順 | 手順書として保存される形が適切 |
| 退職給付金（全般） | **そもそも客層が違う。作らない** |

## 保留：公務員・教員（4,143点）

職業別では圧倒的ですが、**共済制度で傷病手当金のスキームが当てはまりません。**
サービス対象になるか確認するまで、企画を作らない判断です。

対象にできるなら、**この帯だけで10本作れます**（公務員 休職 給料/ボーナス/3年/
通算リセット、教員 休職 復職/伝え方 など）。競合も薄い。
**確認の優先度が最も高い項目です。**

## 全動画共通の注意

- 「もらえる」ではなく「**受給要件に当てはまるか確認できる**」
- 「申請代行」ではなく「**制度の情報提供・相談の同行**」（社労士法）
- 金額は必ず出典と「個人差があります」を添える
- **診断書の取り方を「もらう方法」として語らない**（不正受給の教唆になる）
- 社労士と提携しているなら、**提携先の明示が最強の訴求**
