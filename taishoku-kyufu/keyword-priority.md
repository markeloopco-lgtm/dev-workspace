## 0. 業界の前提（変わらず）

**2025年12月3日、国民生活センターが厚労省と共同で注意喚起。**
相談件数は2021年42件 → 2025年10月末で216件。
「うつ病の診断を受けるためのマニュアルを渡された」という事例が含まれます。

あわせて、**報酬を得て申請書類を作成・提出代行するのは社会保険労務士の独占業務**です。

## 3. ★1位：退職後の手続き群（11,149点）

**v1ではTier B（信頼構築用）と評価していました。実測では最大でした。**

退職した全員が必ず通り、全員が困っていて、**答えが1つに決まる**質問群です。

| # | キーワード | スコア帯 | なぜ効くか |
|---|---|---|---|
| 1 | 任意継続 保険料 / メリット / 必要書類 | 20 | 金額が変わる。全員が迷う |
| 2 | **任意継続 国保 どっちが安い** | 12 | **比較コンテンツの決定版が作れる** |
| 3 | 扶養に入る条件 / 手続き / タイミング | 12〜18 | 収入要件が複雑 |
| 4 | **扶養に入る 失業保険** | 12 | **併給の誤解。相談に直結** |
| 5 | 国民健康保険 減免 / 減免制度 | 17〜20 | 知らないと数万円損する |
| 6 | **国民健康保険 減免 離職コード 33** | 10 | **知っている人だけが得をする。競合ゼロ** |
| 7 | 退職後 健康保険 14日過ぎた | 15 | 焦っている人。今すぐ知りたい |
| 8 | 退職後 健康保険 安くする方法 | 10 | 動機が明確 |
| 9 | 住民税 退職後 / 無職 / 6月 | 10〜20 | 退職翌年に詰む人が多い |
| 10 | 任意継続 やめる / 再就職 / 上限 | 17〜18 | 途中で変えたい人 |

> **ここを押さえると「退職後のことは全部この人に聞けばいい」という位置が取れます。**
> 給付金の相談は、その延長で自然に発生します。売り込まなくていい。

## 4. ★2位：傷病手当金「受給中に働けるか」

金額の話より、**働けるかどうか**が最大の不安でした。

| キーワード | スコア |
|---|---|
| 傷病手当金 アルバイト | 20 |
| 傷病手当金 バイト | 20 |
| 傷病手当金 パート | 20 |
| 傷病手当金 役員 | 20 |
| **傷病手当金 再発 / 2回目** | 20 / 20 |
| 傷病手当金 少ない | 20 |
| 傷病手当金 保険料 / 年金 | 20 / 20 |
| **傷病手当金 つわり** | 20 |

- **「働けるか」で4語（80点）。** ここは1本にまとめて決定版を作る価値があります
- **「再発・2回目」＝ 一度受給した人の再受給。リピート需要がある層**
- **「つわり」＝ 妊娠・切迫流産のセグメント。完全に想定外の市場**
  （別シードでも「切迫流産 休職 給料」が出現）。
  メンタル系一辺倒の競合が触れていない領域です

### 傷病手当金 退職後（1,620点）も引き続き強い

```
退職後 初めて申請（17） / 年金（17） / 書き方（14） / 国保（13）
退職後 扶養に入る（10） / ハローワーク（10） / アルバイト（10）
```

## 5. ★3位：特定理由離職者・受給期間延長（3,555点）

v1の予測が当たった唯一の領域です。

```
特定理由離職者 離職票（20） / 腰痛（20） / パワハラ（20） / 親の介護（20）
特定理由離職者 デメリット（20） / メリット（20） / 延長（20）
特定理由離職者 診断書（16） / 減免（18） / 特定受給資格者（16）

受給期間延長申請書（19） / 受給期間延長 うつ病（10） / 給付制限（10）
```

**「腰痛」「パワハラ」「親の介護」＝ 自分が該当するか知りたい人**です。
該当判定コンテンツ（チェックリスト）と最も相性が良い。

## 6. ★4位：症状×休職（7,100点）— ただし切り口を変更

v1では「症状 × **お金**」と設計しました。**実測では違いました。**

```
適応障害 休職 罪悪感（20）  ← 感情
適応障害 休職 延長 / 1ヶ月 / 半年 / 期間（18〜20）  ← 期間の不安
適応障害 休職 労災（20）    ← 労災という別ルート
鬱 休職 復帰（20） / 転職（16） / 退職（16）
```

**上位は「いつまで休めるのか」「復帰できるのか」「休むことへの罪悪感」。**
お金の話はその後です。

→ **入口を「期間と罪悪感」にして、記事の後半でお金の話に接続する。**
　 いきなり給付金の話をすると、検索意図とズレて離脱します。

## 7. ★5位：失業保険のロングテール（5,118点）

ビッグワード単体は競合が最強なので、具体的な疑問を取ります。

```
失業保険 いくらもらえる（20） / 認定日（20） / 説明会（20） / 待機期間（20）
失業保険 アルバイト（20） / パート（20） / メルカリ（20）  ← 働けるか系がここでも
失業保険 扶養（20） / 年金（20） / 個人事業主（20） / 65歳以上（20）
失業保険 自己都合 再就職手当（20） / 何ヶ月（18） / うつ病（14）
```

**ここでも「アルバイト」「メルカリ」＝ 受給中に稼いでいいか**が上位。
傷病手当金と同じ構造です。**「受給中に働く」で横断コンテンツが作れます。**

---

## 8. 退職代行（5,055点）— 提携先として

失業保険と同格の巨大市場ですが、**すでに固有名詞の勝負**です。

```
退職代行 モームリ（20） / EXIT（20） / イグジット（20） / フォーゲル（20）
```

新規が正面から入る場所ではありません。ただし、

> **退職代行を使う人は、そのまま給付金の対象者です。**
> 同じ人が、同じ時期に、両方を検索しています。

**提携・送客の相手として最も価値が高い**というのが結論です。
コンテンツで狙うなら情報系（`退職代行 デメリット`19、`流れ`19、`40代`20）に限定。

---

## 9. ⚠️ 保留：公務員・教員（4,143点）

職業別では圧倒的です（看護師242点の17倍）。**ただし対象にならない可能性が高い。**

```
公務員 休職 給料（13） / 手当（10） / ボーナス（13） / 3年（13）
公務員 休職 通算 リセット（10）
```

公務員は健康保険が**共済組合**で、**休職中も給与の一定割合が支給されます**（分限休職）。
傷病手当金のスキームがそのまま当てはまりません。

**→ 投資する前に、自社サービスが公務員・教員を受けられるか確認してください。**
　 受けられないなら、この4,143点は取っても1円にもなりません。

## 10. 除外するもの

| 対象 | スコア | 理由 |
|---|---|---|
| **退職給付金** | 2,714 | **会計用語の「退職給付（退職金）」を調べている人。客層が違う** |
| 社会保険給付金サポート | 105 | 市場が存在しない。2番目のサジェストが「怪しい」 |
| 傷病手当金 サポート | 61 | 同上 |
| 休職 保険料 / 休職 生活費 | 224 / 214 | v1で狙い目としたが、需要が小さかった |

### 使ってはいけない表現（変わらず）

- 最大◯◯万円もらえる / 誰でももらえる / 必ずもらえる
- **うつ病の診断をもらう方法**（不正受給の教唆）
- 会社にバレずに
- **申請代行 / 書類作成代行**（社労士の独占業務）

言い換え：「申請代行」→「制度の情報提供・相談の同行」、
「もらえる」→「受給要件に当てはまるか確認できる」。
**社労士と提携しているなら、提携先の明示が最強の訴求です。**
