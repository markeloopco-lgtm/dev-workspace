# 退職給付金サポート｜検索キーワード優先順位

作成日: 2026-08-24
※ 検索ボリュームは未実測。優先度は「成約距離 × 競合の厚さ × 検索意図の明確さ」による設計です。
　 実測手順は末尾の「7. 実データで検証する」を参照。

---

## 0. 先に、前提が変わっている話

**2025年12月3日、国民生活センターが厚生労働省と共同で注意喚起を出しました。**

> 「失業保険の給付額等を増やすことができるとうたう申請サポートに注意
> 　−不正受給を促すかのようなケースも！−」

相談件数は **2021年42件 → 2025年10月末時点で216件**。5倍です。
挙がっている相談は次のようなものです。

- 契約したのに約束された給付金がもらえなかった
- 解約しようとしたら高額な解約料を請求された
- **うつ病の診断を受けるためのマニュアルを渡された**

あわせて、構造的な問題が2つあります。

| 問題 | 内容 |
|---|---|
| **社労士法** | 報酬を得て申請書類を作成・提出代行するのは**社会保険労務士の独占業務**。無資格者が行うと社労士法違反になりうる |
| **「退職給付金」という制度は存在しない** | これは業者側が作った呼称です。国センもこの点を問題視しています |

### キーワード設計への影響（重要）

**「退職給付金」を主軸キーワードにするのは、今からだと悪手です。**

理由は3つ。

1. その名前の制度が存在しないので、**制度を知りたい人は検索しない**
2. 検索する人の多くは「退職給付金 詐欺」「怪しい」で調べる層に変わりつつある
3. 監督官庁が名指ししている語なので、**今後さらにネガティブ検索が増える**

→ **正式名称の「傷病手当金」「失業保険」で組み立ててください。**
　 これが集客上も法務上も、いちばん安全で強い選択です。

## 1. 検索者の心理5段階

キーワードは「その人がどの段階にいるか」で整理すると優先順位が決まります。

```
① 症状だけ自覚      「朝 起きられない」「会社 行きたくない」
        ↓
② 休むことを考える   「適応障害 休職」「診断書 もらい方」
        ↓
③ お金が不安になる   「休職 給料 出ない」「休職 生活費」  ← ★ここが本命
        ↓
④ 制度を調べる      「傷病手当金 いくら」「失業保険 自己都合」
        ↓
⑤ 手続きで詰まる     「傷病手当金 退職後」「特定理由離職者」  ← ★ここも本命
        ↓
⑥ 業者を探す        「傷病手当金 サポート」「申請 代行」（ごく少数）
```

**多くの業者は⑥だけを狙って広告費を溶かしています。**
実際に人がいるのは**③と⑤**です。ここを取るのが勝ち筋です。

## 2. 🚫 Tier 0：使ってはいけないワード

集客効率の問題ではなく、**事業が飛ぶリスク**の問題です。

| ワード・訴求 | なぜダメか |
|---|---|
| 退職給付金 / 退職給付金サポート | 存在しない制度名。国センが名指しで注意喚起 |
| 最大◯◯◯万円もらえる | 誇大広告。国センの相談事例そのもの |
| 誰でももらえる / 必ずもらえる | 受給要件があるので虚偽。景表法・特商法 |
| うつ病の診断をもらう方法 | **不正受給の教唆**。刑事リスク |
| 会社にバレずに / 会社に言わずに | 同上の文脈で読まれる |
| 申請代行 / 書類作成代行 | 社労士の独占業務。無資格なら社労士法違反 |

**言い換えるなら**「申請代行」ではなく「**制度の情報提供・相談の同行**」、
「もらえる」ではなく「**受給要件に当てはまるか確認できる**」。
社労士と提携している場合は、**提携先を明示**するのが最も強い訴求になります。

## 3. ★ Tier S：最優先（③の層・競合が薄い・成約が近い）

**症状 × お金** の交差点。ここが最大の空白地帯です。
制度名で検索できるほど整理がついていないが、切実にお金が不安な人たちです。

| # | キーワード | 検索者の状態 | 成約距離 | 競合 |
|---|---|---|---|---|
| S01 | 適応障害 休職 お金 | 休職を決めたが収入が消えると気づいた | 近 | 薄 |
| S02 | 休職 給料 出ない | 給与明細を見て青ざめている | 近 | 薄 |
| S03 | 休職 生活費 | 家賃・ローンの計算をしている | 近 | 薄 |
| S04 | うつ 休職 収入 | 同上 | 近 | 薄 |
| S05 | 休職 いつまで もらえる | 期間の不安 | 近 | 中 |
| S06 | 退職 貯金ない | 辞めたいが金がない | 近 | 薄 |
| S07 | 休職 保険料 引かれる | 休職中に社保が請求されて驚いた | 近 | **極薄** |
| S08 | 休職 住民税 払えない | 同上 | 近 | **極薄** |
| S09 | 適応障害 傷病手当金 | ②→④への移行点 | 最近 | 中 |
| S10 | 休職 診断書 期間 | 医師に何と言えばいいか | 中 | 中 |

> **S07・S08は誰も書いていません。**
> 休職して初めて「給料ゼロなのに社会保険料と住民税は請求される」と知って
> 検索する人がいます。悩みが具体的で、金額の話なので相談に直結します。

## 4. ★ Tier A：制度名（④の層・ボリューム最大・競合最強）

検索数は最大ですが、**社労士事務所・大手メディア・アフィリエイトが埋め尽くしています。**
単体で正面から狙うのは非効率。**ロングテールで刺す**のが正解です。

| # | キーワード | 優先度 | 備考 |
|---|---|---|---|
| A01 | 傷病手当金 いくら | ★★ | 計算例を実数で出せば勝てる |
| A02 | 傷病手当金 退職後 | ★★★ | **継続給付の条件が複雑＝相談に直結** |
| A03 | 傷病手当金 退職後 いつまで | ★★★ | 通算1年6ヶ月の話。誤解が多い |
| A04 | 傷病手当金 失業保険 両方 | ★★★ | **併給できない**の誤解が非常に多い |
| A05 | 傷病手当金 申請 やり方 | ★★ | 実物の書類を見せると強い |
| A06 | 失業保険 いくら | ★ | 競合が厚すぎる |
| A07 | 失業保険 自己都合 いつから | ★★ | 給付制限の話 |
| A08 | 特定理由離職者 | ★★★ | **語を知っている＝意識が高い。競合が薄い** |
| A09 | 受給期間延長 手続き | ★★★ | 病気で働けない人の必須手続き。競合が薄い |
| A10 | 会社都合 自己都合 変更 | ★★ | パワハラ離職の文脈 |

> **A02・A03・A04・A08・A09が本丸です。**
> ここは「制度が複雑で、間違えると数十万円損する」領域。
> 正確な情報を出すだけで信頼が取れ、相談につながります。

## 5. ★ Tier B：手続き周辺（⑤の層・競合が薄い・信頼構築に最適）

退職直後に**全員が必ずぶつかる**のに、まとめて解説している所が少ない領域です。

| # | キーワード | 競合 | なぜ効くか |
|---|---|---|---|
| B01 | 退職後 健康保険 どうする | 中 | 任意継続か国保かで金額が変わる |
| B02 | 任意継続 国保 どっち 安い | 薄 | **具体的な金額比較。刺さる** |
| B03 | 退職後 国民年金 手続き | 中 | 免除申請を知らない人が多い |
| B04 | 住民税 退職後 払えない | **薄** | 退職翌年の請求で詰む人が多い |
| B05 | 国民健康保険 減免 退職 | **薄** | 離職理由コードで安くなるのを知らない |
| B06 | 扶養に入る 条件 退職 | 中 | 傷病手当金があると扶養に入れない場合がある |
| B07 | 退職後 やること 順番 | 中 | まとめ記事として強い |

> **B04・B05は「知らないと損する」типの最強コンテンツ。**
> 集客というより、**信頼を作って相談に進ませる**役割です。

## 6. Tier C・D：手前の層と、ニッチ

### Tier C：感情ワード（①②の層・ボリューム大・成約は遠い）

認知獲得用。SNS・ショート動画向きで、記事で狙うと効率が悪い。

```
会社 行きたくない / 出社拒否 / 朝 起きられない 会社
仕事 涙が出る / 会社 辞めたい 疲れた / 上司 パワハラ 相談
適応障害 診断 / 適応障害 とは / うつ 初期症状
休職 バレる / 休職 気まずい / 復職 怖い
退職代行  ← 隣接サービス。同じ人が同じ時期に検索する
```

**「退職代行」は特に重要です。** 退職代行を検索する人は、
そのまま給付金の対象者になります。**提携・併記の価値が最も高い隣接ワード**です。

### Tier D：職業別（競合ほぼゼロ・刺さり方が段違い）

| キーワード | 根拠 |
|---|---|
| **看護師 うつ病 転職** | **実測スコア10点**（別途の看護師リサーチで確認済み） |
| 介護士 うつ 退職 | 離職率が高い業界 |
| 保育士 適応障害 | 同上 |
| 教員 休職 お金 | 公務員は共済で制度が違う＝解説需要 |
| SE うつ 休職 | 高年収＝傷病手当金の額も大きい |
| 公務員 休職 給料 | **制度が違うので専用の解説が要る。競合ゼロ** |

> **職業を1つに絞ったランディングページを作ると、変換率が跳ね上がります。**
> 「看護師専門の給付金相談」は、汎用の3倍刺さります。

## 7. 優先順位の結論

```
1位  Tier S（症状×お金）      ← 空白地帯。ここから作る
2位  Tier D（職業別）          ← 競合ゼロ。1職種に絞る
3位  Tier A の A02/A03/A04/A08/A09（制度のロングテール）
4位  Tier B（手続き周辺）      ← 信頼構築
5位  Tier A の残り（制度のビッグワード）
6位  Tier C（感情ワード）      ← SNS・ショート専用
除外 Tier 0                    ← 使わない
```

### 理由

- **上位ほど「競合が薄い × 悩みが具体的 × 金額の話」**で、相談に直結します
- 制度のビッグワード（失業保険 いくら 等）は、社労士事務所と大手メディアが
  何年も積み上げた場所です。**新規が正面から入る場所ではありません**
- 感情ワードはボリュームが大きいですが、**その人はまだお金の話をする段階にいません**。
  認知目的でのみ使ってください

## 8. 実データで検証する

上記は設計であって、実測ではありません。**必ず数字で裏を取ってください。**

看護師チャンネル用に作ったサジェスト収集ツールが、そのまま使えます。

```bash
cd /Users/minrai/dev-workspace/youtube/tools
python3 suggest_kit.py fetch --seeds ../../taishoku-kyufu/seeds.txt \
    --out ../../taishoku-kyufu/suggest.csv --web
```

`--web` を付けているのは、**この領域はYouTubeよりGoogle検索が主戦場**だからです
（休職中の人は動画より記事を読みます）。両方取って比較してください。

取れたら、次の3つを見ます。

1. **Tier Sの語が実際に返ってくるか**（返らなければ需要がない）
2. **想定していなかった語が上位に来ていないか**
3. **「詐欺」「怪しい」系がどれだけ付いているか** ← 業界の逆風の強さが測れます
