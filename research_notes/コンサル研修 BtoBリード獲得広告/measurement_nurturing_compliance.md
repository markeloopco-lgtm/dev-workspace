## 1. KPI設計（CPL・商談単価・受注単価(CAC)・LTV）、許容CPAの逆算、日本のBtoBファネル率

### Takeaway
KPIは「CPL → 商談単価 → 受注単価(CAC) → LTV(粗利)」の順に階層化する。許容CPLは「受注1件の粗利(またはLTV粗利) × 広告費に充てる比率 × 受注率 × 商談化率」で逆算する。日本のBtoBの商談化率は、分母（リードの定義）と経路で 1〜5%（ホワイトペーパーDL）から 20〜40%（問い合わせ・ウェビナー）まで大きく振れる。広告経由リードについては、2025年の330名調査で「11〜20%」が最多帯だった。コンサル・研修・士業に限ったファネル率の信頼できる公開データは見つからなかったため、自社実績を2〜3か月分ためて置き換える前提で設計する。

### Cited Findings
- 売上の分解式として「売上 = リード数 × 商談化率 × 案件化率 × 受注率 × 平均顧客単価」が示されている — [CREX](https://crexgroup.com/ja/marketing/?p=16199)
- BtoBでは、粗利（単発）または LTV ベースの粗利から「限界CPO」を逆算して上限とし、リードCPAは商談・受注への転換率から逆算する、という整理がある — [Start Link（BtoB広告の費用相場 2026）](https://start-link.jp/hubspot-ai/btob-marketing/web-ads-abm/btob-ad-cost-benchmark)、[Start Link（CPLベンチマーク）](https://start-link.jp/hubspot-ai/btob-marketing/web-ads-abm/cpl-benchmark-btob-guide)
- 「CPO」の定義は記事によって「商談1件あたり」と「受注1件あたり」に割れているので、社内で定義を統一する必要がある — 同上（検索要約経由）
- 米国の CPA 計算ツールの一般論として、LTV のうち広告費に回す割合は 50〜70% が利益最大化の範囲とされている（米国・一般論。日本のBtoBの根拠ではない） — [TrueClicks](https://www.trueclicks.com/calculators/calculate-cpa-target)

  - 重視KPIの1位は CVR
  - 年間広告予算は「500万円以上」が定番
  - 調査主体は自社サービスを持つベンダー — [ferret One 第2章 KPI設計と成果](https://ferret-one.com/blog/ad-operation-report-2025-chapter2)、[ferret One 330社調査（広告運用）](https://ferret-one.com/blog/btob-ad-survey-report-2025)

### Inferences
- **KPIの階層（推奨定義）**
  - CPL = 広告費 ÷ 有効リード数（重複・スパム・営業売り込みを除いた数）
  - 商談単価（CPO-商談）= 広告費 ÷ 商談数
  - CAC（受注単価）= 広告費（＋可能なら営業工数）÷ 新規受注数
  - LTV = 平均単価 × 平均継続回数（または継続月数）× 粗利率
  - 月10万〜50万円の規模では受注件数が少なすぎて CAC が毎月大きく揺れる。そのため、日々の運用は CPL と「商談化率」の2指標で回し、CAC/LTV は四半期ごとに確認するのが現実的。
- **許容CPAの逆算式（一般的な導出。上記出典の考え方を式にしたもの）**
  - 許容CAC = 受注1件の粗利（継続型なら LTV 粗利）× 広告費に充てる比率（例: 30〜50%）
  - 許容商談単価 = 許容CAC × 受注率
  - 許容CPL = 許容商談単価 × 商談化率
- **試算例（数値はすべて仮定。自社値に置き換える）**
  - 企業研修（単価80万円、粗利率50%、比率50%、受注率25%、商談化率20%）
    - 許容CAC = 20万円 → 許容商談単価 = 5万円 → 許容CPL = 1万円
    - 月30万円を投下すると、約30リード → 6商談 → 1.5受注
  - コンサル（単価300万円、粗利率70%、比率30%、受注率20%、商談化率15%）
    - 許容CAC = 63万円 → 許容商談単価 = 12.6万円 → 許容CPL = 約1.9万円
  - 税理士顧問（月3.2万円、継続5年と仮定 → 売上192万円、粗利率50%、比率30%、受注率40%、商談化率30%）
    - 許容CAC = 28.8万円 → 許容商談単価 = 約11.5万円 → 許容CPL = 約3.5万円
    - 継続年数は仮定で、出典はない
- **ファネル率の初期値**: 自社実績がないうちは、問い合わせ型リードで商談化率 20〜30%、資料DL型で 3〜5%（ホワイトペーパーは1〜3%もありうる）、商談→受注 20〜30% を「仮置き」にする。そのうえで、受注率は最初の 20〜30 商談で置き換える。商談→受注率については、BtoB全般の信頼できる日本の公開統計を見つけられなかった（Gaps参照）。
- **分母の定義を最初に決めて固定する。** たとえば商談化率の分母を「有効リード（重複・営業売り込み除外）」に統一する。CPL比較が意味を持つ前提になる。

### Gaps
- コンサル・企業研修・士業に特化した「リード→商談化率」「商談→受注率（受任率）」の調査値は見つからなかった（税理士は価格相場のみ）。
- 日本のBtoB全般の「商談→受注率」の信頼できる公開統計も見つからなかった。解説記事の目安値はあるが、出典が不明なものが多い。
- ferret One 調査は記事要約しか見られず、母集団の業種構成や設問の定義を確認できていない。

## 2. 無料ツールでの計測設定（GA4・GTM・Meta Pixel＋CAPI・LinkedIn Insight Tag・Xピクセル・UTM・オフラインCVインポート・簡易CRM）

### Takeaway
最小構成は次のとおり。
- GTM で GA4・Google 広告タグ・Meta Pixel・LinkedIn Insight Tag・Xピクセルを一元管理する
- フォーム送信を GA4 の「キーイベント」（2024年3月に「コンバージョン」から改称）にする
- フォームの hidden 項目で gclid／fbclid／li_fat_id と UTM をリードに保存する
- 商談化・受注を、Google（GCLIDはクリックから90日以内）、Meta（CAPI、イベントから約62日以内とされる）、LinkedIn（90日以内）へ戻す

Google はオフラインCVインポートから「リードの拡張コンバージョン」への移行を推奨している。API経由のアップロードは 2026年6月15日以降 Data Manager API に移行した。Meta の旧 Offline Conversions API は 2025年5月に廃止され、通常の CAPI に一本化された。HubSpot 無料CRMは、2024年9月以降に作成したアカウントで「2ユーザー・1,000コンタクト」程度に制限されたと報じられている。小規模なら スプレッドシート＋HubSpot無料版 で足りる。

### Cited Findings
- **GA4**
  - 2024年3月（3月27日発表とする記事あり）、GA4の「コンバージョン」が「キーイベント」に改称された — [デジタルアイデンティティ](https://digitalidentity.co.jp/blog/analytics/conversion-change-keyevent.html)
  - 改称の狙いは Google 広告の「コンバージョン」との混同回避で、既存設定の作り直しは不要 — [Strategy Code](https://strategy-code.com/marketing-colum/ga/key-event/)
  - GTM で送るイベントをキーイベントに設定する手順の解説 — [free web hope](https://www.fwh.co.jp/knowledge/data-analysis/ga4-keyevent/)
- **Google 広告のオフライン取り込み**
  - GCLID の保持は 90 日間。最後のクリックから 90 日以上経ってアップロードされたオフラインCVはインポートされない — [Google 広告ヘルプ: オフライン コンバージョンをインポートするためのガイドライン](https://support.google.com/google-ads/answer/15081888?hl=ja)

  - 拡張コンバージョンとリードの拡張コンバージョンは、2026年4月以降に単一の設定へ統合される予定と案内されている — 同上（検索要約）

### Inferences
- **タグ実装チェックリスト（すべて無料）**
  1. GTM コンテナを全ページに設置する。
  2. GA4 設定タグを入れ、フォーム送信完了イベント（例: `generate_lead`）をキーイベントにする。
  3. Google 広告のコンバージョンタグ＋リードの拡張コンバージョンを、フォームのメールアドレスを使って設定する。
  4. Meta Pixel（Lead イベント）を入れる。CAPI はサーバー実装が必要なので、まずは Pixel のみ。CRM から受注・商談イベントを手動 CSV か API で送るのは第2段階でよい。
  5. LinkedIn Insight Tag と、CV（フォーム送信）を設定する。
  6. Xピクセルは X 広告を使う場合だけ入れる。
  7. サンクスページは URL を分けるか、送信完了イベントを発火させる。
  8. 二重計上を避けるため、GA4 キーイベントの Google 広告へのインポートと、Google 広告タグの CV は、どちらか一方を「メイン」にする（運用上の推奨）。
- **UTM規約の例**
  - `utm_source` = google / meta / linkedin / x / newsletter
  - `utm_medium` = cpc / paid_social / email
  - `utm_campaign` = YYYYMM_目的_オファー（例: 202611_lead_wp-jinji）
  - `utm_content` = クリエイティブID
  - 小文字・ハイフン区切りで統一し、スプレッドシートに台帳を作る。
- **オフラインCVのフィードバック手順（スプレッドシート運用）**
  1. LP フォームに hidden 項目（gclid、fbclid、li_fat_id、utm_*、LP URL）を置き、リード管理シートに自動記録する（Google フォームや HubSpot 無料フォーム経由）。
  2. シートに「ステータス（リード/MQL/商談/受注/失注）」「ステータス日付」「金額」列を作る。
  3. 週1回、商談・受注を CSV にして Google 広告（クリックから90日以内）、Meta（イベントから約62日以内）、LinkedIn（90日以内）にアップロードする。
  4. 月10万〜50万円では商談・受注が月数件しか出ないため、入札の最適化目標はしばらく「リード」のままにする。商談・受注は「サブ（観測用）コンバージョン」として取り込み、媒体間・キャンペーン間の質の比較に使うのが現実的。
- **API 移行は管理画面ユーザーには直接関係しない。** Data Manager API への移行（2026年6月15日）は API 利用者向けの変更と読める。管理画面から CSV をアップロードする小規模運用への影響は限定的と推測される（要確認）。
- **CRM は段階的に入れる。** コンタクトが1,000件未満で営業2名以内なら HubSpot 無料版で足りる。それを超えるまではスプレッドシートを正本にする構成でも問題ない。

### Gaps
- Google・Meta・LinkedIn・X の公式ヘルプの本文は読めておらず、数値（90日・62日・90日）は検索要約と二次記事に基づく。特に Meta の 62 日と「コンバージョンリード」の条件は、Meta 公式ドキュメントで未確認。
- 2026年4月の「拡張コンバージョン統合」の具体的な画面変更は確認できていない。
- Google 広告のリマーケティングリストの最小人数、Meta カスタムオーディエンスの最小人数は今回確認していない。
- GA4 の推奨イベント `generate_lead` と Google 広告インポートの最新仕様は公式で未確認。

## 3. リードの選別（MQL/SQL定義、スコアリング、フォームでの絞り込み、法人メール判定）

### Takeaway
小規模事業者なら、MA ツールの点数制より「属性（業種・規模・役職）× 行動（問い合わせ／見積・相談依頼か、資料DLか）」の簡易ルールで足りる。MQL は「接触してよいリード」、SQL は「BANT（予算・決裁者・ニーズ・時期）の一部が確認できた商談候補」と定義する。フリーメールは「除外」ではなく「減点」にするのが安全。士業の顧客層（中小企業や個人事業主）はフリーメール利用が多いためだが、これは推論で、データは見つからなかった。

### Cited Findings
- MQL はマーケティングから営業・インサイドセールスへ引き継げるリードで、定義は会社ごとに違う。MA ツールならスコアで、アナログ運用では「BANT の一部が未確定なら MQL」とする例がある
- SQL のアナログ定義案は「BANT が明確」「導入率の高い業種・部署」「トライアル申込など確度の高い行動」 — [Rocket Boys](https://rocket-boys.co.jp/what_is_mql_sql/)
- 典型的な流れは「属性＋行動でスコアリングし、しきい値超えを MQL に → インサイドセールスが電話で BANT を確認 → SQL」。リードスコアが一定値を超えた、特定セミナーに参加した、などの基準を使う — [SalesNow DB](https://salesnow.jp/db/knowledge/73)
- スコアリングの定石は、問い合わせ・見積依頼に高得点、展示会の名刺スキャンなどに低得点 — [マイナビ TECH+](https://news.mynavi.jp/techplus/article/enterpriseit-newtrend-64/)
- 商談化率50%超の企業を対象にした調査（ラクス、2025年8月、118人）では、優先順位付けに行動情報（資料請求、問い合わせ、ウェビナー参加、サイト訪問履歴、メール反応）を使うと答えた人が 28.2% — [配配メール（ラクス）](https://www.hai2mail.jp/news/2025/20250918.php)

### Inferences
- **簡易スコアリング表（例、100点満点）**
  - 行動:
    - 相談・見積依頼 +50
    - 料金ページ閲覧 +10
    - ウェビナー参加 +20
    - 資料DL +10
    - メールリンククリック +5
  - 属性:
    - ターゲット業種 +10
    - 従業員規模がターゲット帯 +10
    - 役職が決裁者・部門長 +15
    - 法人ドメインのメール +5
  - 減点:
    - 競合・同業 −50
    - 学生・個人の学習目的 −30
  - 判定: 50点以上 = MQL（48時間以内に架電）、70点以上または相談依頼 = 即日対応。
- **フォーム項目の絞り込み**
  - 必須（4〜6項目）: 会社名、氏名、メール、電話、従業員規模（選択式）、検討時期（選択式: 3か月以内/半年以内/情報収集）。
  - 任意: 役職、課題（選択式）、予算感。
  - 研修会社なら「対象人数」、士業なら「相談分野」と「法人/個人」を選択式で入れると、架電前に優先順位を付けられる。
  - 項目を増やすと CVR が下がるトレードオフがある。資料DL（入口）は軽く、相談申込（出口）は重くする。
- **法人メール判定**
  - フリーメールドメイン（gmail.com、yahoo.co.jp、icloud.com、outlook.jp/outlook.com、hotmail.co.jp、キャリアメール等）を判定リストにして、スプレッドシートの関数で「フリー/法人」を自動判定する。
  - 士業の顧客は小規模事業者が多いので、フリーメールは減点にとどめ、除外しない。

### Gaps
- フリーメール利用率や、フリーメール由来リードの商談化率に関する日本のデータは見つからなかった。
- 小規模事業者向けの MQL しきい値の実証データはない（例示はすべて推論）。

## 4. フォロー速度とインサイドセールス（応答時間の効果、架電・メール・日程調整ツール、フォロー手順）

### Takeaway
海外研究（2007 MIT/InsideSales、2011 HBR、いずれも非日本・旧データ）では、1時間以内、さらには5分以内の接触が、連絡がつく率と商談化率を大きく高めると繰り返し報告されている。日本でも、商談化率の高い企業の約半数は初回接触が当日〜2日以内で、目標達成したインサイドセールス担当の半数超は30分以内に架電している（いずれも自己申告の相関データ）。小規模事業者の現実的な基準は「営業時間内の相談依頼は30分〜1時間以内に電話、資料DLは当日中にメール＋翌営業日に電話」。日程調整は TimeRex 無料版か HubSpot 無料版のミーティングリンクで済む。弁護士は面識のない者への電話・訪問による広告が禁止されている（規程5条）点に注意する。

### Cited Findings
- **HBR "The Short Life of Online Sales Leads"（2011年3月、米国）**
  - 1時間以内に接触を試みた企業は、1時間後の企業に比べてリードを「qualify」できる確率が約7倍、24時間以上の企業に比べて60倍超。「qualify」は意思決定者と意味のある会話ができたことを指す — 二次引用: [CrankWheel](https://crankwheel.com/how-to-massively-increase-the-chance-of-qualifying-sales-leads/)、[Venture Harbour](https://ventureharbour.com/how-fast-do-marketing-leads-turn-cold-and-how-to-stop-it-happening/)
  - 同論文は米国2,241社に対するテストリードの監査で、平均応答42時間、23%は無応答だった、とする紹介がある — [ainora.lt（二次・2026）](https://ainora.lt/blog/lead-response-time-statistics-every-study-2026)
  - 一方で「29社B2C・13社B2B、125万リード」を HBR のデータとする二次記事もあり、サンプルの記述は一致しない — 同上、[SmartCompany](https://www.smartcompany.com.au/marketing/20110704-are-you-letting-online-leads-go-cold/)
- **MIT/InsideSales.com "Lead Response Management Study"（2007年10月、米国）**
  - 発表者は Dave Elkington（InsideSales.com）と James Oldroyd（MIT Sloan）
  - データは6社・3年分、1.5万件超のリードと10万回超の架電。電話接触に関する研究で、成約率は扱っていない — [研究スライド PDF](https://www.mortech.com/hs-fs/hub/25649/file-13535879-pdf/docs/mit_study.pdf)
  - InsideSales の自社ページは「5分以内なら30分後に比べて接触率100倍、qualify率21倍」としているが、スライド抜粋では倍率を直接確認できなかった。100x/21x はしばしば HBR と誤って帰属される — [InsideSales](https://resources.insidesales.com/?p=4167)、[ainora.lt](https://ainora.lt/blog/lead-response-time-statistics-every-study-2026)
- XANT の2014年レポートでは、電話での初回応答時間の中央値は3時間8分（米国・二次引用） — [manamina（ヴァリューズ）](https://manamina.valuesccg.com/articles/3643) 周辺の検索要約
- **日本: ラクス×PRIZMA リサーチ（2025年8月、平均商談化率50%以上のBtoB企業の担当者118人）**
  - リード発生から初回接触までは「即日（当日中）」25.4%、「1〜2日以内」25.4% が最多
  - 共通項は「対応スピード」「接触頻度」「優先リードの見極め」
  - 高商談化率企業だけを対象にしており、速度別の比較ではない — [配配メール](https://www.hai2mail.jp/news/2025/20250918.php)、[PR TIMES](https://prtimes.jp/main/html/rd/p/000000103.000017058.html)、[SalesZine](https://saleszine.jp/news/detail/7631)
- 日本: IDEATECH の調査では、目標を100%以上達成したインサイドセールス担当者の半数以上が、リードの行動から「30分以内」に電話している — [manamina](https://manamina.valuesccg.com/articles/3643)
- 日本・事例: ある製造業では、問い合わせに24時間以内に詳しく返信するようにしたところ、商談化率が30%→50%（1.7倍）になったと報告されている — [BeMARKE](https://be-marke.jp/articles/tips-altenas1)
- **日程調整ツール**
  - TimeRex 無料プラン: 日程調整回数は無制限。Google/Outlook カレンダー、Zoom/Teams/Meet と連携でき、リマインドメールとリスケ機能もある。日程調整カレンダーは1つまで、考慮できるのは2人まで。ベーシックは月750円（年契約） — [ITreview](https://www.itreview.jp/products/timerex/price)、[kigyolog](https://kigyolog.com/tool.php?id=2452)

  - HubSpot 無料版の個人ミーティングリンクは1個 — [Start Link](https://start-link.jp/hubspot-ai/hubspot/onboarding-pricing/free-crm-comparison)
- 弁護士の業務広告規程5条は、面識のない者（現在・過去の依頼者、友人、親族、これらに準ずる者以外）への訪問・電話による広告を禁じている。6条は、特定事件の当事者で面識のない者に郵便等で直接勧誘することを禁じている — [shopowner-support 解説](https://www.shopowner-support.net/?p=3545)、[第二東京弁護士会資料](https://niben.jp/niben/pdf/shiminkaigi_42.pdf)

### Inferences
- **フォローSLA（小規模向けテンプレート）**
  - 相談・見積依頼:
    - 営業時間内なら30分以内に架電（不在時はSMSかメールで「お電話しました」＋日程調整リンク）
    - 営業時間外なら自動返信メールで日程調整リンクを送り、翌営業日の午前に架電
  - 資料DL:
    - 即時に自動メールで資料を送付（同意を得ていれば）
    - 当日中に担当者名で短いメール（課題を尋ねる1問＋日程リンク）
    - 1〜2営業日後に架電1回。不在なら3営業日後と7営業日後に再架電
    - つながらなければナーチャリングへ移す
  - ウェビナー参加:
    - 当日中にお礼メール＋アンケート（「個別相談希望」チェック）
    - 希望者には24時間以内に架電

- **1人事業・少人数での実装**
  - フォーム通知を Gmail と スマホ（Slack や LINE 通知）の両方に飛ばす。
  - 自動返信に日程調整リンク（TimeRex 無料版）を入れて「速度」を機械化する。顧客が自分で予約できるので、電話がつながらない問題も緩和できる。
- **弁護士の場合**: 問い合わせを受けた相手への折り返しは、相手から依頼のあった連絡で、5条が禁じる「面識のない者への電話による広告」とは性質が違うと考えられる。ただし、資料DLだけで面談を依頼していないリードへの架電は、所属弁護士会に確認したほうがよい（推論・要確認）。

## 5. ナーチャリング（ステップメール・メルマガ、リターゲティング、ウェビナー招待、資料DL→商談化の典型期間、無料・安価ツール）

### Takeaway
日本企業のBtoB購買は「1か月以上3か月未満」の検討が最多で、購買プロセスの約3分の1が進んでから営業と接点を持つ（2022年調査）。資料DLリードの商談化率は1桁%台が多いため、DL直後の即時フォロー、2〜6週間のステップメール、月1〜2回のメルマガ、月1回程度のウェビナー招待、リターゲティング広告を組み合わせ、3〜6か月かけて再浮上を待つ設計が妥当。ただし「資料DL→商談化までの平均期間」の信頼できる数値は見つからなかったので、自社CRMで中央値を測る。メール配信には特定電子メール法上の同意（6章）が必要。

### Cited Findings
- 「Japan Sales Report 2022」によると、日本企業のBtoB購買期間は「1か月以上3か月未満」が最多で、購買金額が大きいほど長い。購買者は購買プロセスの約3分の1が経過してから営業と接点を持つ — [PR TIMES（Japan Sales Report 2022）](https://prtimes.jp/main/html/rd/p/000000066.000015189.html)
- BtoBの検討期間は「数か月〜1年以上」「平均3〜6か月」などと解説記事によって幅があり、業界・商材・金額で変わる — [ferret One（BtoB購買プロセス）](https://sol.ferret-one.com/blog/btob-purchasing-process)、[Medix](https://btob.medix-inc.co.jp/blog/btob_btoc_marketing_method_differences)
- ホワイトペーパーの商談化率は1〜3%で資料請求（20〜40%）より低い、とする解説表がある — 検索要約（[BizArena SalesFirst](https://salesfirst.bizarena.jp/articles/b2b-lead-to-meeting) 周辺。特定は曖昧）
- 商談化率の高い企業は接触頻度も重視している — [SalesZine（ラクス調査）](https://saleszine.jp/news/detail/7631)
- HubSpot 無料版のマーケティングメールは月2,000通まで（2024年9月以降のアカウント） — [Start Link](https://start-link.jp/hubspot-ai/hubspot/onboarding-pricing/free-crm-comparison)
- 「資料DLから5〜10件の商談」につながる調査PR型コンテンツの事例紹介がある（ベンダー記事） — [SyncAd](https://syncad.jp/news/71886/)

### Inferences
- **ナーチャリング設計（月10万〜50万円規模）**
  1. **即時**（DL直後）: 資料送付メール。自己紹介と「無料相談」導線を入れる。
  2. **ステップメール**（2〜6週間で4〜6通）。テーマの例:
     - 課題の整理
     - 事例（守秘義務に配慮し、匿名化または書面同意を取る。7・8章参照）
     - よくある失敗
     - 料金の考え方
     - FAQ
     - 期間限定でない相談会の案内
  3. **メルマガ**（月1〜2回）: 法改正・助成金・制度の解説など、士業や研修会社が強みを出しやすい時事テーマ。
  4. **ウェビナー**（月1回か隔月、Google Meet や Zoom 無料枠）: 既存リードを招待し、参加者を「行動スコア+20」でMQL化する。
  5. **リターゲティング**: 資料DL者・LP訪問者に、事例や無料相談の広告を少額（月予算の10〜20%）で配信する。
  6. **休眠掘り起こし**: 3か月・6か月時点で「近況確認」メール1通＋架電1回。
- **費用ゼロで組む場合**: HubSpot 無料版（1,000コンタクト・月2,000通）をメール配信と追跡に使う。超えたら有料化するか、無料枠のある国産配信ツールに乗り換えるかを判断する（無料枠の詳細は未調査）。
- **KPI**: ナーチャリング経由の「再浮上率」（MQL化／総リード）と、資料DLから商談化までの日数の中央値をスプレッドシートで追う。目安は最初の6か月でホワイトペーパー型リードの3〜5%が商談化すること。前出の1〜5%帯からの推論。

### Gaps
- 資料DL→商談化までの平均日数・月数の信頼できる日本の調査は見つからなかった。
- ステップメールの通数・開封率・クリック率の日本のBtoBベンチマークは今回確認していない。
- リターゲティングの最小オーディエンス要件（Google・Meta・LinkedIn）は未確認。
- 無料プランのある国産メール配信ツールの最新条件は未調査。

## 6. 予算管理（テスト期間、停止・拡大ルール、クリエイティブの入れ替え、少ないCV数での結果の読み方）

### Takeaway
月10万〜50万円では、Meta の学習完了の目安（最後の大きな編集から7日間で約50件の最適化イベント）や Google のスマート入札の目安（4〜6週間で30〜50件のCVとする実務解説）に届かないことが多い。そのため、媒体・キャンペーン数を絞り、2〜4週間単位で判断する。停止ルールは「目標CPLの2〜3倍を使ってCV0」とする。ポアソン近似では、実力が目標どおりでも、目標CPLの1倍分ではCV0が約37%、2倍で約14%、3倍で約5%の確率で起こる。だから「1倍でCV0」で止めるのは早すぎ、「3倍でCV0」なら高い確度で目標未達と判断できる。

### Cited Findings
- **Meta の学習期間**
  - 学習期間は日数ではなく件数で決まる。広告セットごとに、最後の大きな編集から7日間で約50件の最適化イベントが目安 — [株式会社禅](https://zen-web.co.jp/column/meta-learning-period/)、[noside](https://noside-ltd.co.jp/blog/meta-learning/)
  - 学習中に予算・オーディエンス・クリエイティブを変えると学習がリセットされる。7日以上停止すると事実上リセットされる — 同上（二次。Meta 公式の目安を引用）
  - 初動1週間は手を加えない運用が結果的に一番伸びた、という事例がある — [libero](https://libero.jp/blog/meta-ads-learning-period.html)
- Google 広告の自動入札の学習は通常5〜14日で、その間のCPA高騰は正常な挙動 — [SEM Agency markelab](https://sem-agency.co.jp/markelab/ad-media/auto-bidding-relearning-loop/)
- 撤退・縮小判断の目安として、Google 広告（スマート入札）は最低4〜6週間・30〜50CV（目標CPA×50件分の消化）とする表がある — [新作堂](https://shinsakudo.com/blog/web-advertising/ad-campaign-exit-kpi-threshold-design/)
- 学習中は最低14日、または30件のCVがたまるまで設定変更を避けるべき、とする解説もある — 検索要約（[SEM Agency](https://sem-agency.co.jp/markelab/ad-media/auto-bidding-relearning-loop/) 周辺）
- 「目標CPAの2倍・3倍を使ってCV0なら停止」という基準を明記した公式・調査ソースは見つからなかった（後述の推論で統計的に補う）
- **A/Bテスト一般（海外）**
  - 1バリアントあたり最低1,000訪問者、有意水準95%が一般的な基準。期間は4〜6週間が妥当な上限で、6週間で差が出なければ効果が小さすぎる可能性がある
  - 早すぎる停止は代表的な失敗 — [Spotler](https://spotler.com/blog/how-many-visitors-do-you-need-to-run-a-valid-a-b-test)、[Seer Interactive](https://seerinteractive.com/blog/not-enough-traffic-for-ab-testing)

### Inferences
- **統計の目安（ポアソン近似による計算。外部出典なし）**
  - 真のCPLが目標どおりなら、目標CPL × k 円を使ったときのCV0の確率は e^(−k)。
    - k = 1: 約37%
    - k = 2: 約13.5%
    - k = 3: 約5%
  - よって「目標CPLの3倍を消化してCV0」は約95%の確度で未達と判断でき、停止または大幅修正に値する。2倍は「要診断（LP・ターゲティング・計測を確認）」の水準。
  - 月5件と10件の差は統計的には大きくない（ポアソンでの5件の95%区間はおおよそ1.6〜11.7件）。月10〜30件規模で、クリエイティブ間のCPL差が1.5倍程度なら「誤差の範囲」とみなす。
- **停止・拡大ルール（例）**
  - 停止: 広告セットやキーワード単位で、目標CPLの3倍を消化してCV0。または、30日で目標CPLの1.5倍超が続き、商談化率も平均以下。
  - 要診断: 目標CPLの2倍消化でCV0。まず計測（タグ・サンクス発火）、LP表示速度、フォームエラーを確認する。
  - 拡大: 目標CPL以下が2週間続き、リードの最低5件以上が商談化している。増額は1回20〜30%程度を週1回まで。学習リセットを避けるため、Meta の「大きな編集」を減らすという趣旨の推論。
- **月額予算別の構成（推論）**
  - 10万円/月: 1媒体1キャンペーン（例: Google 検索の指名＋ニッチキーワード、または Meta 1広告セット）。クリエイティブは2〜3本。
  - 30万円/月: 2媒体まで（検索＋Meta または LinkedIn）。リターゲティングに10〜20%。
  - 50万円/月: 2〜3媒体。新規クリエイティブのテスト枠を予算の20%に固定する。
  - どの規模でも、Meta で「50件/7日」を満たすのは非現実的（CPL1万円なら週50万円が必要）。CV最適化で「学習限定」になっても慌てず、2〜4週間単位で判断する。
- **クリエイティブの入れ替え**: 2〜4週間ごとに、成績下位1本を新案に差し替える。同時に差し替えるのは1〜2要素（訴求軸 or 画像）に限り、何が効いたかを判別できるようにする。頻度（フリークエンシー）が上がりCTRが下がってきたら疲労と判断する（一般的な運用慣行で、出典なし）。

### Gaps
- 「目標CPAのN倍消化でCV0なら停止」の業界標準ソースは見つからなかった（上の基準は統計計算による推論）。
- Google 広告の目標CPA入札の推奨CV数（過去30日の件数など）は公式ヘルプで未確認。
- クリエイティブ疲労の定量基準（フリークエンシー等）の信頼できるソースは見つからなかった。

## 7. 個人情報保護法（利用目的、プライバシーポリシー、第三者提供、2022改正、2026改正）と電気通信事業法の外部送信規律

### Takeaway
個人情報保護法の改正（いわゆる3年ごと見直し）は、2026年4月7日に閣議決定、7月10日に成立、7月17日に公布された（令和8年法律第56号）。施行は公布から2年以内の政令で定める日で、2026年10月時点では主要部分が未施行とみられる。主な内容は課徴金（不正取得・不正利用型）、16歳未満の個人情報、特定生体個人情報、統計作成・AI関連の同意例外、漏えい本人通知の一部緩和。BtoBリード獲得を直撃する新規制は少ない。

2022年改正の「個人関連情報」規律により、Cookie 等を提供先が個人データとして取得することが想定される場合は、本人同意の確認が必要になった。

外部送信規律（2023年6月施行）は「電気通信事業を営む者」が対象で、自社の会社概要や商品・サービスを宣伝するだけのサイトは「自己の需要」のための運営として対象外と整理されている。ただし、オンラインメディアのような他者向けの情報提供自体が事業になっているサイトは対象になりうる。対象外でも、Cookie・タグの利用はプライバシーポリシーで公表しておくのが無難。

## 8. 特定電子メール法（営業メール・メルマガのオプトイン義務、表示義務）

### Takeaway
特定電子メール法は、営業目的の広告宣伝メールに原則オプトイン（事前同意）を求める。BtoB（法人宛て）も対象。例外は次の3つ。
- 名刺など書面で本人からアドレスの通知を受けた場合
- 取引関係にある場合
- 団体・営業者がウェブで公表しているアドレス（「広告メールお断り」の併記がない場合）

送信時は送信者の氏名・名称、住所、苦情・問い合わせ先、受信拒否の通知先などを表示し、同意の記録を保存する。資料DLフォームでは「メルマガ・セミナー案内の配信に同意する」旨を明示して同意を取るのが基本。

### Cited Findings
- 2008年改正で、取引関係などの一部の場合を除き、事前に同意した相手にだけ広告宣伝メールを送れる「オプトイン方式」が導入された — [総務省資料（2008年12月）](https://www.soumu.go.jp/main_sosiki/joho_tsusin/policyreports/chousa/shohi/pdf/081215_2_18-6.pdf)
- 例外の詳細:
  - 書面（名刺等）で本人からアドレスを受け取った場合は例外。ただし通信販売の広告メールは承諾が必要とする解説がある — [IT トレンド](https://it-trend.jp/mail_delivery/article/28-0022)
  - 団体や営業を営む個人がウェブ上でアドレスを公表している場合も例外だが、「広告・宣伝メールはお断り」の併記があれば例外にならない — [琴平綜合法律事務所コラム](https://www.kottolaw.com/column/000037.html)、[日本データ通信協会](https://www.dekyo.or.jp/soudan/contents/taisaku/1-2.html)
- 表示義務は、送信者の氏名・名称、住所、苦情・問い合わせの受付先、受信拒否の通知先など — [blastmail](https://blastmail.jp/blog/mailmagazine/mail-law)
- 2008年改正では、送信者情報の表示義務と同意の記録保存も盛り込まれたと報じられた — [GIGAZINE（2008）](https://www.gigazine.net/news/20080212-anti-spam/)、[ITmedia オルタナティブ・ブログ（2008）](https://blogs.itmedia.co.jp/goyat/2008/02/post-37ef.html)
- 罰則について、2008年当時の報道では法人の罰金上限を100万円から3,000万円に引き上げるとされた（送信者情報の偽装や命令違反が対象。原案段階の報道） — [GIGAZINE（2008）](https://www.gigazine.net/news/20080212-anti-spam/)
- 所管は総務省と消費者庁 — [日本データ通信協会](https://www.dekyo.or.jp/soudan/contents/taisaku/1-2.html)
- 特定電子メール法上は例外に当たる場合でも、通信販売の広告メールには特定商取引法がかかり、事前同意が必要になることがある — [actionlink](https://actionlink.jp/column/mail/specified-email-act/)
- 名刺交換・問い合わせ対応だけで送ってよいかの「既存関係」の線引きと罰則の解説 — [トップコート国際法律事務所](https://topcourt-law.com/corporate-legal/consent-electronic-mail-act)
- BtoB メールでも例外に当たるかを送信先ごとに判断し、配信停止の申し出があった相手には例外の有無にかかわらず送らない運用が重要 — [funnel-ai](https://funnel-ai.jp/media/tokutei-denshi-mail-hou/)

### Inferences
- **チェックリスト**
  1. 資料DL・ウェビナー申込フォームに「当社からのメールマガジン・セミナー案内等の広告宣伝メールの受信に同意します」と明示する（チェックボックスか、ボタン付近への明記）。同意文言、取得日時、フォームURLを記録しておく。
  2. 名刺交換・展示会で得たアドレスは例外に当たりうるが、送信前に「今後ご案内をお送りしてよいか」の確認メール1通で同意を取り直すと安全。
  3. ウェブで公表されている法人アドレスへのコールドメールは例外になりうる。ただし「広告メールお断り」の表示がないかを確認し、記録する。
  4. 全メールのフッターに、送信者名、住所、問い合わせ先、ワンクリック（または簡単な）配信停止リンクを入れる。
  5. 配信停止は即時に反映させる（HubSpot 無料版の配信停止機能を使う）。
- **個別フォロー（1対1）メールの扱い**: 問い合わせへの返信や、依頼された資料の送付は、通常は「広告宣伝」目的の特定電子メールには当たらないと考えられる（推論）。ただし本文にセミナー案内などの宣伝を混ぜる場合は同意のある相手に限るのが無難。

### Gaps
- 現行の罰則額（個人・法人）、同意記録の保存期間（「最後の送信から1か月」とする説があるが未確認）、総務省・消費者庁「特定電子メールの送信等に関するガイドライン」の本文は確認できなかった。
- 「デフォルトでチェック済み」の同意欄が有効かどうかについて、ガイドラインの最新の扱いは未確認。

## 9. 景品表示法（優良誤認・有利誤認、No.1表示、ステマ規制、「お客様の声」「実績」表現）

### Takeaway
景表法は「一般消費者」に対する不当表示を規制する（5条）。純粋な事業者間（BtoB）取引の表示にどこまで及ぶかは、今回の調査では確定できなかった。それでも、研修や士業の広告は個人事業主・一般消費者の目にも触れるうえ、士業規程や不正競争防止法にも同趣旨の規制があるので、景表法の基準で作るのが安全。

主な現行ルール:
- ステマ告示（2023年10月1日施行）: 違反主体は広告主。初の措置命令は2024年6月6日（医療法人）
- 改正景表法（2024年10月1日施行）: 故意の優良誤認・有利誤認に直罰（100万円以下の罰金、法人両罰）を新設。確約手続（第1号認定は2025年2月26日）、再違反の課徴金割増しも導入
- No.1表示: 消費者庁の実態調査報告書（2024年9月26日）が「顧客満足度No.1」などの主観評価型No.1や「〇%が推奨」表示に、合理的根拠を求める考え方を示した
- 体験談: 「個人の感想です」と添えても、体験談が示す効果の打消しにはならない

### Cited Findings
- 景表法5条は「一般消費者に対し」実際より著しく優良・有利と示す表示を禁止している。目的は一般消費者の自主的・合理的な選択の確保 — [千葉県 景品表示法資料（令和7年度）](https://www.pref.chiba.lg.jp/annou/hyouji/documents/r7keihyou.pdf)、[東京都資料](https://www.shouhiseikatu.metro.tokyo.lg.jp/torihiki/hyoji/keihyo/documents/naikakuhukokuji.pdf)
- 「表示」はウェブサイトやカタログなど、顧客を誘引する手段全般を含む。BtoB取引が適用除外になるかを直接述べた資料は見つからなかった — 同上（検索要約）
- **ステマ告示**
  - 消費者庁は2023年3月28日に景表法5条3号に基づく告示「一般消費者が事業者の表示であることを判別することが困難である表示」と運用基準を公表し、2023年10月1日に施行した — [Impress Watch](https://www.watch.impress.co.jp/docs/news/1489089.html)
  - 違反主体はインフルエンサー等ではなく広告主（事業者） — [薬事法ドットコム](https://www.yakujihou.com/knowledge/stealth/)
  - 初の措置命令は2024年6月6日付で、医療法人社団に対するもの — [イノベンティア](https://innoventier.com/archives/2024/07/17138)
- **2024年10月1日施行の改正景表法**
  - 確約手続、課徴金の返金方法の弾力化、課徴金額の推計規定、再違反時の課徴金割増し、直罰の新設、国際的な執行の整備などが導入された — [all-senmonka（Moneyizm）](https://www.all-senmonka.jp/moneyizm/80296)、[データ・マックス](https://data-max.co.jp/article/73309)

  - 刑事罰は広告主だけでなく広告代理店・アフィリエイターも対象になるとする解説がある — [all-senmonka](https://www.all-senmonka.jp/moneyizm/80296)
- **確約手続と措置命令の件数**
  - 第1号の確約計画認定は2025年2月26日（caname株式会社「かたぎり塾」）
  - 2026年5月20日時点で公表された確約事例は9件
  - 措置命令は2023年度44件 → 2024年度26件（因果は不明） — 検索要約（[アンダーソン・毛利・友常 ニューズレター](https://amt-law.com/asset/pdf/bulletins19_pdf/250415.pdf)、[キング&ウッド・マレソンズ](https://www.kwm.co.jp/blog/premiums-and-representations-act/)、[BUSINESS LAWYERS](https://www.businesslawyers.jp/articles/1409) のいずれか。特定は曖昧）
- **No.1表示の実態調査報告書（2024年9月26日公表）**
  - 対象は「顧客満足度No.1」等の表示と、「医師の90%が推奨」など第三者の主観的評価を指標とする表示。合理的根拠がなければ景表法上問題になる

  - 2023年度の措置命令44件のうち、No.1表示を含む不当表示は13件 — [のぞみ総合法律事務所](https://www.nozomisogo.gr.jp/newsletter/10874)
  - 事業者は、調査会社・コンサル経由で調査を依頼しながら、具体的なアンケート内容を把握していない例が多かった — [NTT東日本](https://business.ntt-east.co.jp/column/bizdrive/no1-label-consumer-check.html)
  - 「No.1調査しませんか」という営業の実態と注意点 — [Web担当者Forum](https://webtan.impress.co.jp/e/2024/12/06/48216)、[日本マーケティング・リサーチ協会](https://www.jmra-net.or.jp/activities/trend/domestic/20241119.html)
- **体験談・打消し表示**
  - 体験談に「個人の感想です」等が付いていても、体験談で示された効果の打消しにはならない
  - 強調表示と同じ視野にない打消し表示や、著しく小さい文字の打消し表示は問題になるおそれがある
  - 被験者数・属性、効果が得られた人と得られなかった人の割合などを明瞭に示すべきとされる。根拠は消費者庁「打消し表示に関する実態調査報告書」（2018年） — [ネットショップ担当者フォーラム](https://netshop.impress.co.jp/node/7209)、[経産省資料（2023）](https://www.meti.go.jp/shingikai/mono_info_service/platform_economics/pdf/2023_003_02.pdf)

### Inferences
- **「お客様の声」「実績」表現のチェックリスト（コンサル・研修・士業向け）**
  1. **お客様の声は実在・実名（または属性）・書面同意を確保する。** 謝礼や無料提供の見返りで書いてもらった声は、関係を明記する（ステマ告示の趣旨）。広告主が依頼・指示して第三者に投稿させた口コミは、「広告」「PR」の表示がなければステマに当たりうる。
  2. **成果の数値には母数と期間を併記する。** 例: 「受講企業の離職率30%改善」→「2024〜2025年度の受講企業12社のうち、事後アンケートで回答のあった8社の平均。効果を保証するものではありません」。それでも打消しで誤認は消えないので、典型的でない好事例を一般化しない。
  3. **No.1・満足度表示は避ける。** 調査会社の「イメージ調査」型のNo.1（非利用者への印象アンケート）は特に避ける。使う場合は、自社顧客の満足度調査を自社で実施し、調査主体・対象・時期・母数を近接表示する。
  4. **「導入社数〇〇社」「研修実績〇万人」は算定方法を確認できる状態にしておく**（重複・延べ数の明記）。
  5. **価格表示:**
     - 「通常価格〇円→今だけ〇円」は、比較対照価格に販売実績がないと有利誤認になりうる
     - 「無料相談」は、本当に無料の範囲（時間・回数）を明記する
     - 期間限定をうたうなら、実際に期間を守る
  6. **効果の断定は禁止**（「必ず」「確実に」「100%」）。士業はさらに厳しい（9章）。
  7. **事業者向けだから景表法は無関係と判断しない。** BtoB取引でも、広告が個人事業主や一般消費者に届けば規制対象となりうる。BtoB取引の表示には不正競争防止法（品質等誤認表示）も別途ありうる。ただし後者は今回出典で確認できていない。

### Gaps
- 景表法の BtoB（事業者向け）表示への適用範囲について、消費者庁の公式見解は確認できなかった。
- 不正競争防止法の品質誤認表示規定（2条1項20号）の BtoB 広告への当てはめは未調査。
- No.1報告書・打消し表示報告書・ステマ運用基準の原文は確認できていない。

## 10. 士業ごとの広告規制（弁護士・税理士・社労士・行政書士）

### Takeaway
4士業とも、業務広告は原則自由化されている（弁護士は2000年、税理士は2001年以降）。そのうえで、会規や倫理規程で次の広告を禁止するのが共通の骨格。
- 事実に反する広告、誤導・誤認のおそれがある広告、誇大・過度な期待を抱かせる広告
- 特定の同業者との比較広告
- 品位を損なう広告

弁護士は「勝訴率の表示」「面識のない者への訪問・電話による広告」「顧問先・依頼者名の表示（書面同意なしの場合）」を明示的に禁止。税理士は2019年1月から「困惑させ、又は過度な不安をあおる広告」を禁止に追加。社労士は連合会のネットパトロールで、2021年以降1,034件を指摘し797件を是正した。「100%経営者の味方」のような労使中立に反する表現が問題視されている。行政書士は職務基本規則・倫理で品位保持を求めるが、広告条文の本文は確認できなかった。

### Cited Findings
- **弁護士**（日弁連「弁護士等の業務広告に関する規程」「業務広告に関する指針」）

  - 4条1号: 訴訟の勝訴率の表示を禁止。顧問先・依頼者の名称（書面同意がある場合を除く）や受任中事件の表示も制限 — [日弁連 業務広告に関する指針（PDF、2012年全部改正、2014年・2018年・2021年改正）](https://www.nichibenren.or.jp/library/pdf/jfba_info/rules/other/shishin_kaiki_44.pdf)、[まほろばブログ](https://design.mahoroba.co.jp/blog/other/1583/)、[ilc.gr.jp](https://ilc.gr.jp/law/88.html)

- **士業広告の共通NG表現（4士業共通で避ける）**

  - 「他の事務所より〇〇」（特定の同業者との比較）

## 11. 研修会社の助成金訴求（「助成金で実質無料」等の表現リスク）

### Takeaway
人材開発支援助成金は、事業主が訓練経費を「全額負担」していることが前提で、その一部を助成する制度。負担はゼロにならない（群馬県の例では支払経費266,200円に対し実質55,990円）。厚労省・労働局は「助成金で実質無料」と勧誘する訓練機関・コンサルについて注意喚起している。キャッシュバックや返金で事業主が実質的に全額負担していない場合は受給できず、不正受給になる。審査は厳格化され、2026年も企業名の公表が続いている。研修会社の広告では「実質無料」「0円」「必ずもらえる」は使わず、助成率・上限・要件・審査を明記する。

### Cited Findings
- 制度は、事業主が雇用する労働者に職務関連の訓練を計画に沿って実施した場合に、訓練経費や訓練期間中の賃金の一部を助成するもの — [厚労省 資料](https://www.mhlw.go.jp/content/11800000/001325363.pdf)、[キャリア形成・学び直し支援センター資料](https://carigaku.mhlw.go.jp/wp-content/uploads/2023/11/e2552750053d3ea9e1266f4ab1732c8d.pdf)
- 群馬県の資料の例では、中小企業の支払経費266,200円に対し、助成活用後の実質経費は55,990円 — [群馬県資料](https://www.pref.gunma.jp/uploaded/attachment/650443.pdf)
- 1事業所が1年度に受給できる助成額の上限は1,000万円。受給には、年度単位で訓練実施計画を事前に届け出る必要がある — 検索要約（[厚労省資料](https://www.mhlw.go.jp/content/11806001/001274375.pdf)、[秋田労働局資料](https://jsite.mhlw.go.jp/akita-roudoukyoku/content/contents/002144110.pdf)）
- 「助成金を活用して従業員に訓練を実質無料で受けさせることができる」などとうたう訓練機関やコンサルの情報が厚労省等に寄せられている。返金などで事業主が実際には全額を負担していなければ受給できない — [HRトラスト（厚労省・労働局の注意喚起の紹介）](https://www.hr-trust.jp/news/14969/)
- 厚労省は不正受給防止のため審査を厳格化し、提出資料を追加した。事業主・訓練会社向けリーフレットを改定し、不正につながるケースを例示する方針 — [労働新聞社](https://www.rodo.co.jp/news/214431/)
- 訓練委託先（エッグフォワード株式会社）から資金提供を受けて訓練経費の支払いに充てたスキームが、不正として紹介されている（専門家のSNS投稿。一次資料は未確認） — [マルホ総研 X投稿](https://x.com/isyokenmei/status/2006255815611850766)
- 典型的な偽装は、企業が経費を一度支払ったように見せ、講師・研修ベンダー・子会社からキャッシュバックを受けるもの — [cloudfree 解説（2025年11月）](https://cf534936.cloudfree.jp/2025/11/02/grant-fraud-cashback-risks/)
- 不正受給時は、返還に加えて不正受給額の2割相当の加算額の納付、雇用関係助成金の不支給などが定められているとする解説 — [FMクラブ](https://www.fmclub.jp/blog/risk/75)
- 人材開発支援助成金とデジタル化・AI導入補助金の不正受給について、2026年も企業名の公表が続いている — [PR社労士・行政書士事務所](https://prorelations.jp/?p=917)
- 「実質無料」をうたう広告そのものに対する厚労省の注意喚起文書の本文は、検索では見つからなかった — 検索結果（上記）

### Inferences
- **研修会社の広告表現ガイド**
  - NG:
    - 「助成金で実質無料」「実質0円」「負担ゼロ」「必ずもらえる」「受給率100%」
    - 「キャッシュバック」「ポイント還元」「紹介料」で負担を相殺するスキーム全般（広告だけでなく取引設計として不可）
  - 推奨:
    - 「人材開発支援助成金の〇〇コースの対象となる場合、要件を満たせば訓練経費の最大〇%（中小企業の場合）等が助成される可能性があります。受給には事前の計画届と労働局の審査が必要で、受給を保証するものではありません」
    - 具体的な試算は「支払総額」と「助成予定額」を並べて示す
  - 助成率・上限額は年度ごとに改定されるので、広告に載せる数値は厚労省の最新パンフレットで確認し、年度を明記する。
- **景表法との関係**: 個人事業主や一般消費者向けの講座で「実質無料」とうたえば、有利誤認のリスクもある。法人向けでも、不正受給スキームへの関与は研修会社自身の信用失墜と公表リスクにつながる（推論）。
- **社労士との連携**: 助成金の申請代行は社労士の独占業務にあたる。研修会社が申請書類の作成を代行する訴求は避け、「提携社労士をご紹介」などの表現にとどめる（社労士法の一般知識に基づく推論。要確認）。

### Takeaway
2026年10月時点で押さえるべき変化は次の5点。士業規程（弁護士・税理士）の大きな改正は今回の調査では見つからなかった。
