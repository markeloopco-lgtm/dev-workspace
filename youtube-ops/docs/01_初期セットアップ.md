# 01. 初期セットアップ手順

所要時間の目安: 1〜1.5時間（Google Cloudの画面操作が中心）。
上から順にやれば動きます。つまずいたら各ステップの「※」を確認してください。

---

## Step 1. Google Cloud プロジェクトを作る（無料）

「Google Cloud」= GoogleのAPI利用管理画面です。課金設定は不要です（無料枠のみ使用）。

1. https://console.cloud.google.com/ を開き、スプレッドシートを管理するGoogleアカウントでログイン
2. 画面上部のプロジェクト選択 →「新しいプロジェクト」→ 名前は `youtube-ops` など → 作成
3. 左上メニュー「APIとサービス → ライブラリ」で以下2つを検索して**有効化**:
   - **YouTube Data API v3**（投稿・動画情報用）
   - **YouTube Analytics API**（分析データ用）

## Step 2. OAuth同意画面を設定する

「OAuth」= 各チャンネルのGoogleアカウントに「このツールにYouTube操作を許可しますか？」
と確認する仕組みです。

1. 「APIとサービス → OAuth同意画面」
2. User Type は **外部** を選択（社外のGoogleアカウントのチャンネルも認証できるように）
3. アプリ名（例: `YouTube運用ツール`）・メールアドレスを入力して保存
4. スコープ追加画面は**スキップでOK**（スクリプト側で要求します）
5. **重要**: 「公開ステータス」を **本番環境** にする（「アプリを公開」ボタン）
   - ※ テスト状態のままだと**リフレッシュトークンが7日で失効**し、毎週認証し直しになります
   - ※ 本番環境でもGoogleの審査は不要。認証画面に「このアプリはGoogleで確認されていません」
     と警告が出ますが、「詳細 → （アプリ名）に移動」で進めます（自分たち専用ツールなので問題ありません）

## Step 3. OAuthクライアントを作る

1. 「APIとサービス → 認証情報 → 認証情報を作成 → OAuthクライアントID」
2. 種類は **ウェブアプリケーション**
3. 「承認済みのリダイレクトURI」に次を追加（`{スクリプトID}` は Step 4 の後で確定するので、
   一旦仮で作成 → Step 4 の後にここへ戻って追記してもOK）:
   ```
   https://script.google.com/macros/d/{スクリプトID}/usercallback
   ```
4. 作成すると **クライアントID** と **クライアントシークレット** が表示される → メモしておく

## Step 4. スプレッドシートとGASを用意する

1. Googleドライブで新規スプレッドシートを作成（名前は「YouTube運用管理」など）
2. メニュー「拡張機能 → Apps Script」を開く
3. 左側「エディタ」で、このリポジトリの `src/` の各ファイルを1つずつ作成して貼り付ける
   - 「＋ → スクリプト」でファイル名（例: `00_config`）を付けて内容をコピペ。全ファイル分繰り返す
   - ※ Node.jsが使える人は `clasp` でまとめてpushしても良い
4. **OAuth2ライブラリを追加**: 左側「ライブラリ ＋」→ スクリプトIDに
   `1B7FSrk5Zi6L1rSxxTDgDEUsPzlukDsi4KGuTMorsTQHhGBzBkMun4iDF` を入力 → 検索 →
   最新バージョンを選択 → ID（userSymbol）が `OAuth2` になっていることを確認 → 追加
5. 「プロジェクトの設定（歯車アイコン）」で:
   - 「appsscript.json マニフェストをエディタで表示する」にチェック → エディタに出てきた
     `appsscript.json` をこのリポジトリの内容で置き換え
   - **スクリプトID** をコピー → Step 3 のリダイレクトURIに反映
6. 同じ「プロジェクトの設定」の下部「スクリプト プロパティ」に以下を追加:

   | プロパティ名 | 値 |
   |---|---|
   | `OAUTH_CLIENT_ID` | Step 3 のクライアントID |
   | `OAUTH_CLIENT_SECRET` | Step 3 のクライアントシークレット |
   | `GEMINI_API_KEY` | Gemini APIキー（https://aistudio.google.com/apikey で無料発行） |

   ※ 機密情報はすべてここに置きます。**シートには絶対に書かない**でください

## Step 5. シートを初期化してチャンネルを登録する

1. スプレッドシートを再読み込み → メニューに「📺 YouTube管理」が出る
2. 「① 初期セットアップ（シート作成）」を実行
   - 初回は権限の承認画面が出ます（スプレッドシート所有者として承認）
3. 「04_チャンネル設定」にチャンネルを1行ずつ登録:
   - **チャンネルキー**: 半角英数の短い名前（例: `companyA`）。後から変えない
   - **モード**: `ANALYTICS`（分析のみ）/ `DRAFT`（分析＋AI生成）/ `FULL`（投稿まで）
   - **承認モード**: `REVIEW`（AI生成後に人間が承認）/ `AUTO`（完全自動）
   - **テンプレID**: 「05_概要欄テンプレ」のID（例: `default`）
   - **有効**: チェックを入れる
   - しきい値列は空欄でOK（既定値が使われる。後から調整可能）

## Step 6. チャンネルごとにOAuth認証する

1. メニュー「認証URLを発行（全チャンネル）」を実行 → 「認証URL」列にURLが入る
2. **各チャンネルの所有者**に、そのチャンネルを管理しているGoogleアカウントでログインした
   状態で認証URLを開いてもらい、承認してもらう
   - ※ 事前に、そのアカウントへ**このスプレッドシートの閲覧権限**を共有しておくこと
     （Apps Scriptの認証ページにアクセスするために必要）
   - ※ 「このアプリはGoogleで確認されていません」→「詳細 → 移動」で続行
   - ※ ANALYTICSとDRAFTのチャンネルには読み取り権限のみ、FULLのチャンネルには
     アップロード権限も要求されます（自動で切り替わる）
3. 全チャンネル承認できたら「認証状態を確認」を実行 →
   「認証済み(投稿可) / チャンネル名」等になればOK。「⚠アカウント不一致」が出たら
   別アカウントで承認してしまっているので、URLを開き直して正しいアカウントで承認

## Step 7. 動作確認と自動実行の開始

1. 「分析を今すぐ更新」を実行 → 「02_動画分析」「03_日次ログ」「00_ダッシュボード」に
   データが入ることを確認
2. FULLチャンネルで投稿テスト:
   - Driveに短いテスト動画とサムネ画像（2MB以下）を置く
   - 「01_投稿管理」に1行入力（チャンネルキー・タイトル・動画DriveURL・サムネDriveURL・
     予約公開日時は30分以上先を推奨）→ ステータスは空欄のまま
   - 「AI概要欄を生成（選択行）」→ 内容確認 → 「承認」にチェック
   - 「投稿キューを今すぐ実行」→ ステータスが「予約済み」になり videoId とURLが入ればOK
   - ※ 最初は**限定公開や非公開の捨てチャンネル**で試すのが安全です
3. 問題なければ「② トリガー設定（毎日自動実行を開始）」を実行
   - 毎朝5時に分析、10分おきに投稿キューが自動で回ります（時刻は `00_config.gs` で変更可）

---

## チャンネルを追加するとき（2社目以降・将来の20〜50ch化）

1. 「04_チャンネル設定」に1行追加（＋必要なら「05_概要欄テンプレ」にテンプレ追加）
2. そのチャンネルの所有者アカウントへスプレッドシートを閲覧共有
3. 「認証URLを発行」→ 所有者に承認してもらう → 「認証状態を確認」

これだけです。GCP側の作業は不要（5社すべてGoogleアカウントが違っていても、
同じOAuthクライアントで各自が承認する方式のため対応できます）。
投稿本数が1日6本を超える規模になったら README の「既知の制限」を参照してください。
