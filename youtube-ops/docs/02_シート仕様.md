# 02. シート仕様（列の意味）

「入力」= 人間が入れる列 / 「自動」= スクリプトが書く列（手で編集しない）

---

## 00_ダッシュボード（全列自動）

分析実行のたびに全体を作り直します。手で書き込んでも消えるので閲覧専用。

- 上段: チャンネル別サマリー
  - チャンネル / モード / 認証 / 登録者数 / 90日再生 / 平均CTR(%) / 投稿本数(90日) /
    直近7日再生 / 要改善 / ヒット / 急上昇 / 投稿予定 / エラー
  - 「要改善」= サムネ改善候補・サムネ差し替え優先・インプレッション不足・CTR低下のいずれかが付いた動画数
- 下段: 判定付き動画の一覧（要改善が先・最大30件）
- 個別チャンネルを深掘りするときは「02_動画分析」でチャンネルキー列をフィルタ

## 01_投稿管理

| 列 | 入力/自動 | 説明 |
|---|---|---|
| 投稿ID | 自動 | 内部管理用の連番（空のままでよい） |
| チャンネルキー | **入力** | 04_チャンネル設定のキー |
| タイトル | **入力** | 動画タイトル（100字まで） |
| 動画DriveURL | **入力** | Google Drive上の動画ファイルのURL |
| サムネDriveURL | **入力** | サムネ画像のURL（2MB以下・省略可） |
| 予約公開日時 | **入力** | 公開したい日時（10分以上先）。空欄なら非公開でアップのみ |
| カテゴリID | 入力(任意) | YouTubeカテゴリ番号。空欄なら22（ブログ・人物） |
| タグ | 入力(任意) | カンマ区切り。空欄ならAIのSEOキーワードが自動で入る |
| 台本・文字起こし | 入力(任意) | AI概要欄の材料。長文OK（先頭2万字を使用） |
| AI概要欄 | 自動(編集可) | 生成された概要欄。**投稿前に手直ししてOK** |
| 固定コメント案 | 自動 | AIが作る固定コメント候補（投稿は手動。APIでは固定化できないため） |
| 承認 | **入力** | REVIEWモード時、チェックを入れると投稿キューに進む |
| ステータス | 自動 | 下記「ステータスの流れ」参照 |
| videoId / YouTube URL / 投稿完了日時 | 自動 | 投稿成功後に記録 |
| エラー内容 | 自動 | 失敗理由。解消したらステータスを「投稿待ち」に手で戻すと再試行される |

### ステータスの流れ

```
(空欄/下書き)
   → AI生成
       ├ FULL × AUTO   → 投稿待ち → アップロード中 → 予約済み／公開済み／アップ済(非公開)
       ├ FULL × REVIEW → 確認待ち →(承認✓)→ 投稿待ち → …
       └ DRAFT         → 生成済み（ここで終了。投稿はしない）
   ※ 失敗時は「エラー」＋エラー内容
   ※ 「アップロード中(継続)」は大きい動画を分割転送している途中の表示（放置でOK）
```

## 02_動画分析（全列自動）

全チャンネルの動画データベース。チャンネルキー列でフィルタ・並べ替えして
「CTRランキング」「再生数ランキング」「初動(24h)ランキング」「7日再生ランキング」等として使う。

| 列グループ | 説明 |
|---|---|
| videoId〜経過日数 | 動画の基本情報 |
| 再生回数(累計) | 公開からの累計（Data API） |
| 再生(90日)〜コメント数 | 直近90日間の集計（Analytics API）。インプレッション・CTR・平均視聴時間/視聴率・総再生時間・登録者増・高評価・コメント |
| 前日比再生 / 3日増加 / 7日増加 | 日次ログから計算した増分（伸びの速度） |
| 24h再生 / 3日再生 / 7日再生 / 30日再生 | 公開後その時点での累計再生。**投稿時期が違う動画同士の比較用**。一度記録したら固定（±1日程度の誤差あり。記録開始前に公開された古い動画は空欄） |
| 登録獲得効率(/千再生) | 90日登録者増 ÷ 90日再生 × 1000 |
| 判定 / 判定メモ | 自動判定の結果（docs/03参照）。サムネ差し替え候補の抽出はここをフィルタ |

公開から90日を過ぎた動画は更新が止まり、最後の値が残ります。

## 03_日次ログ（全列自動）

毎朝の分析実行時に「その日の値」を1動画1行で追記するスナップショット。
前日比・CTR推移・マイルストーンの計算元。基本は見なくてよいシートですが、
特定動画の推移を折れ線グラフにしたいときはここからvideoIdでフィルタして作る。
行数が5万行を超えると古い順に自動削除される（上限は `00_config.gs` で変更可）。

## 04_チャンネル設定

| 列 | 入力/自動 | 説明 |
|---|---|---|
| チャンネルキー | **入力** | 半角英数の識別子。**後から変更しない**（全シートの紐付けキー） |
| チャンネル名 | **入力** | 表示名（例: A社メイン） |
| YouTubeチャンネルID | 自動(入力可) | UC〜のID。空欄なら認証時に自動記入。**認証アカウントの照合**にも使う |
| モード | **入力** | ANALYTICS / DRAFT / FULL |
| 承認モード | **入力** | REVIEW（人間確認あり）/ AUTO（完全自動投稿） |
| テンプレID | **入力** | 05_概要欄テンプレのID |
| 有効 | **入力** | チェックを外すと分析・投稿の対象外 |
| 認証状態 / 認証URL | 自動 | 認証フロー用（docs/01のStep 6） |
| CTR改善閾値(%) | 入力(任意) | この絶対値未満で「サムネ改善候補」。空欄なら「チャンネル平均CTR×0.8未満」 |
| CTR低下警告(pt) | 入力(任意) | 7日前よりこのポイント下がったら「CTR低下」。既定0.5 |
| ヒット倍率 | 入力(任意) | 7日再生がチャンネル平均の何倍で「ヒット」。既定2 |
| 急上昇倍率 | 入力(任意) | 日次再生が直近7日平均の何倍で「急上昇」。既定3 |
| インプ判定倍率 | 入力(任意) | インプレッションが平均の何倍あれば「表示は十分」とみなすか。既定1.5 |

## 05_概要欄テンプレ

チャンネルごとのトンマナ維持用。1行=1テンプレ。複数チャンネルで同じテンプレIDを共有してもよい。

| 列 | 説明 |
|---|---|
| テンプレID | 04で指定するID（例: `default`, `companyA`） |
| 固定ヘッダー / 固定フッター | 概要欄の先頭/末尾に毎回入る定型文（リンク集・免責など） |
| 固定ハッシュタグ | 毎回必ず入れるタグ（スペース区切り） |
| CTA文 | 登録誘導などの決まり文句。**空欄ならAIが生成** |
| トンマナ・AI追加指示 | AIへの指示（例: 「敬語。絵文字禁止。ターゲットは40代経営者」） |
| チャプター生成 | チェックすると台本からチャプター案を生成して概要欄に入れる |

概要欄の組み立て順: 固定ヘッダー → AI要約 → CTA → チャプター → ハッシュタグ（固定＋AI）→ 固定フッター

## 06_エラーログ（全列自動）

自動処理の失敗履歴（日時・種別・チャンネル・対象・メッセージ・詳細）。
「毎朝ダッシュボードのエラー列が0でない」→ ここを見る、という使い方。2000行で自動ローテート。
